# คู่มือลงเวลาและลา (โมดูล 3–4)

## หน้าหลักของพนักงาน (สรุปของฉัน)
คนที่ลงเวลาเห็นการ์ดสรุปใต้ปุ่มลงเวลา แตะการ์ดเพื่อไปดูรายละเอียด:

| การ์ด | แสดง | แตะแล้วไปที่ |
|---|---|---|
| ตำแหน่งงานวันนี้ | ตำแหน่ง คลัง กะ เวลาพัก ที่หัวหน้าจัดให้ | ตำแหน่งงานวันนี้ |
| OT เดือนนี้ | ชั่วโมง OT ที่อนุมัติแล้ว แยกตามอัตรา + ชั่วโมงที่รออนุมัติ (นับตามวันที่ 1 ถึงวันนี้ของเดือนปฏิทิน) | ลงเวลา (ท้ายหน้า) |
| วันลาคงเหลือ | คงเหลือ / สิทธิ์ ของแต่ละประเภทลา ปีนี้ | ลางาน |
| ใบลาล่าสุด | 3 ใบล่าสุด พร้อมสถานะ | ลางาน |


## ลงเวลา (ทุกคน) — เมนู "ลงเวลา"

1. กด **เข้างาน** ตอนมาถึง และ **ออกงาน** ตอนกลับ
2. ครั้งแรกเบราว์เซอร์จะถามขอใช้ตำแหน่ง ให้กด **อนุญาต**
3. ต้องอยู่ **ในรัศมีของคลัง** เท่านั้น ถ้าอยู่นอกพื้นที่ ระบบไม่บันทึกและบอกว่าห่างกี่เมตร
4. เวลาที่บันทึกเป็นเวลาของเซิร์ฟเวอร์ แก้นาฬิกาในมือถือไม่มีผล
5. กะดึก (เช่น 20:00–05:00) กดออกตอนเช้า ระบบนับเป็นวันที่เริ่มกะให้เอง
6. ระบบเก็บพิกัดเฉพาะตอนกดลงเวลา ไม่ติดตามตำแหน่งตลอดเวลา และไม่ถ่ายรูป

### อนุญาตตำแหน่ง (แอปบอกวิธีเองตามเครื่อง)
- **ครั้งแรก:** หน้าลงเวลามีการ์ด "ครั้งแรก: อนุญาตให้แอปใช้ตำแหน่ง" กดปุ่ม **อนุญาตตำแหน่ง** แล้วตอบมือถือว่า **อนุญาต / ขณะใช้แอป** (อย่ากด "ไม่อนุญาต")
- **เคยกด "ไม่อนุญาต" ไปแล้ว:** เว็บขอซ้ำเองไม่ได้ ต้องเปิดในการตั้งค่า แอปจะแสดงขั้นตอนทันทีที่เปิดหน้า ตามเครื่องที่ใช้ (สลับดูของเครื่องอื่นได้ เช่น หัวหน้าช่วยลูกทีม):

| เครื่อง | ขั้นตอนโดยย่อ | หลังแก้เสร็จ |
|---|---|---|
| Android (Chrome) | แตะไอคอนหน้าชื่อเว็บ → สิทธิ์ → ตำแหน่ง → อนุญาต · ถ้าไม่มี: ตั้งค่ามือถือ → แอป → Chrome → สิทธิ์ → ตำแหน่ง | กด "ลองใหม่" |
| Samsung Internet | แตะแม่กุญแจหน้าชื่อเว็บ → สิทธิ์ → ตำแหน่ง → อนุญาต (หรือกดปุ่ม "เปิดใน Chrome") | กด "ลองใหม่" |
| iPhone (Safari) | แตะ "aA" → การตั้งค่าเว็บไซต์ → ตำแหน่งที่ตั้ง → อนุญาต · ถ้าไม่ได้: การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → บริการหาตำแหน่ง (เปิด) → เว็บไซต์ของ Safari → ขณะใช้งานแอป | กด "โหลดหน้าใหม่" |
| iPhone (Chrome) | การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → บริการหาตำแหน่ง → Chrome → ขณะใช้งานแอป | กด "โหลดหน้าใหม่" |
| ติดตั้งเป็นแอปบนหน้าจอแล้ว | iPhone: เหมือน Safari · Android: กดค้างไอคอน → ⓘ → สิทธิ์ → ตำแหน่ง | ปิดแอปแล้วเปิดใหม่ |
| เปิดลิงก์ใน LINE / Facebook | ปุ่ม "เปิดใน Chrome / Safari" (LINE หาตำแหน่งไม่ได้บ่อย) | ลงเวลาในเบราว์เซอร์ |

- **GPS ปิด:** Android ปัดหน้าจอลงแล้วแตะ "ตำแหน่ง" · iPhone เปิด "บริการหาตำแหน่ง"
- **หาไม่ทัน:** ออกไปใกล้ประตู/ที่โล่ง (หลังคาเหล็กทำให้ GPS ช้า) แล้วลองใหม่
- ใต้ปุ่มเข้า-ออกงานมีลิงก์ **"ตำแหน่งมีปัญหา? ดูวิธีแก้"** เปิดดูได้ทุกเมื่อ · มีทั้งภาษาไทยและพม่า
- ชื่อเมนูอาจต่างกันเล็กน้อยตามรุ่นมือถือ ถ้ายังไม่ได้ ให้หัวหน้า "แก้เวลาแทน" หรือพนักงานกด "ขอแก้เวลา"

**ลืมกด / GPS ใช้ไม่ได้:** กด **ขอแก้เวลา** ได้จาก: ปุ่ม "ลืมลงเวลา? กดขอแก้เวลา" ใต้ปุ่มเข้า-ออกงาน · ลิงก์เดียวกันใต้ปุ่มลงเวลาในหน้าหลัก · เมนู "ขอแก้เวลา" (เปิดฟอร์มของวันนี้ทันที เปลี่ยนวันที่ได้) และปุ่มในแต่ละวันของประวัติ (ขาด / ยังไม่เข้า / ลืมเข้า-ออก / สาย / ออกก่อน)
แล้ว ใส่เวลาเข้า-ออกและเหตุผล → หัวหน้างานอนุมัติ → เวลาถูกบันทึกและล็อก
(ขอย้อนหลังได้ตามจำนวนวันที่ตั้งไว้ ค่าเริ่มต้น 31 วัน)

## ติดตามการเข้างาน (หัวหน้างานขึ้นไป)

- **รายวัน:** มาแล้วกี่คน ต้องตามกี่คน (สาย / ยังไม่เข้า / ขาด / ลืมเข้า-ออก) กดกรองตามสถานะได้ และกด "แก้เวลาแทน" ได้
- **สรุปรายเดือน:** วันมาทำงาน สาย (ครั้ง/นาที) ออกก่อน ขาด ลืมเข้า-ออก ลา ทำงานวันหยุด ส่งออก CSV ได้
- **คำขอแก้เวลา:** อนุมัติ / ไม่อนุมัติ (ต้องใส่เหตุผล) — อนุมัติคำขอของตัวเองไม่ได้

สถานะคำนวณจาก **ตารางกะ + เวลาจริง + ใบลาที่อนุมัติ** ในฐานข้อมูลที่เดียว:

| สถานะ | ความหมาย |
|---|---|
| ปกติ | เข้า-ออกตามกะ (รวมเวลาผ่อนผันที่ตั้งไว้) |
| สาย / ออกก่อน | เกินเวลาผ่อนผัน แสดงจำนวนนาทีนับจากเวลาเริ่ม/เลิกกะ |
| ยังไม่เข้า | กะเริ่มแล้วแต่ยังไม่กดเข้า |
| ขาด | เลยเวลาเลิกกะแล้วไม่มีเวลาเข้า-ออกเลย |
| ลืมออก / ลืมเข้า | มีแค่เวลาเข้า หรือแค่เวลาออก |
| ลา / ลาครึ่งวัน | มีใบลาที่อนุมัติแล้ว |
| วันหยุด / ทำงานวันหยุด | กะเป็น OFF/HOL |

**เริ่มนับขาดงานตั้งแต่ 19 พ.ย. 2569** (ตั้งที่ ตั้งค่า → ลงเวลา → "วันเริ่มใช้ลงเวลาในแอป" · แก้ได้โดยเพิ่มค่าใหม่พร้อมวันที่เริ่มใช้)
- ก่อนวันนั้น วันที่ไม่มีเวลาเข้า-ออกขึ้นว่า "ยังไม่เริ่มใช้" ไม่นับขาด
- ตั้งแต่วันนั้น คนที่ **มีกะทำงาน แต่ไม่กดลงเวลาเข้า-ออกเลย และไม่มีใบลาที่อนุมัติแล้ว** = **ขาด** (นับเมื่อเลยเวลาเลิกกะ)
- ยื่นใบลาแล้วแต่ **ยังรออนุมัติ** ยังขึ้นว่าขาด จนกว่าหัวหน้าจะอนุมัติ · ลืมกดแต่มาทำงานจริง ให้ขอแก้เวลา → อนุมัติแล้วสถานะเปลี่ยนเอง
- **ตารางกะ** (เมนู ตารางกะ / ตารางกะหัวหน้าคลัง): วันที่ขาดมีกรอบแดงและป้าย **"ขาด"** ในช่องกะ (ชี้ที่ช่องเพื่อดูคำอธิบาย) ใต้แถบสีบอกจำนวน "เดือนนี้ N คน-วัน"
  มุมมองรายวันมีป้าย "ขาดงาน" หลังชื่อ และสรุป "ขาดงาน N คน"
- เริ่มวันเดียวกันนี้: แจ้งเตือนลืมลงเวลา แจ้งหัวหน้าเมื่อขาดติดต่อกันตามจำนวนวันที่ตั้งไว้ (ค่าเริ่มต้น 3 วันทำงาน) และเริ่มคิดเบี้ยขยัน
- ตารางกะต้องตรงกับที่ทำงานจริง: ถ้าใส่กะทำงานไว้ในวันที่ให้หยุด คนนั้นจะถูกนับขาด ให้แก้กะเป็น OFF

## ลางาน (ทุกคน) — เมนู "ลางาน"

1. ดู **วันลาคงเหลือ** แต่ละประเภท
2. กด **ยื่นใบลา** เลือกประเภท วันที่ เต็มวัน/ครึ่งเช้า/ครึ่งบ่าย และใส่เหตุผล
3. **จำนวนวันลานับเฉพาะวันทำงานตามตารางกะ** (ไม่นับ OFF/HOL) ถ้าเดือนนั้นยังไม่มีตารางกะ นับทุกวันยกเว้นวันนักขัตฤกษ์
4. ลาป่วยแนบ **ใบรับรองแพทย์** ได้ (รูปหรือ PDF ไม่เกิน 5 MB) เห็นเฉพาะเจ้าของ หัวหน้า และผู้อนุมัติ
5. ยกเลิกได้ทันทีถ้ายังไม่อนุมัติ ถ้าอนุมัติแล้วต้องกด **ขอยกเลิก** ให้ผู้อนุมัติกดยืนยัน
6. ลาเกินโควตายังยื่นได้ แต่ใบจะติดป้าย "เกินโควตา" ให้ผู้อนุมัติเห็น

## อนุมัติใบลา (หัวหน้างานขึ้นไป)

- **ขั้น 1:** ระดับถัดไปของผู้ลา — พนักงาน → หัวหน้างาน/แอดมินของคลังนั้น · หัวหน้างาน/แอดมิน → ผู้จัดการแผนกขึ้นไป · ผู้จัดการแผนก → ผู้จัดการฝ่ายขึ้นไป ([คู่มือบทบาทและลำดับอนุมัติ](คู่มือบทบาทและลำดับอนุมัติ.md))
- **ขั้น 2:** ถ้าลา **ตั้งแต่ 4 วัน** (ตั้งค่าได้) ต้องให้ **ผู้จัดการแผนกขึ้นไป** อนุมัติต่อ
- ผู้จัดการอนุมัติตั้งแต่ขั้นแรก = ครบทุกขั้น
- ผู้จัดการฝ่ายขึ้นไปไม่ใช้ระบบลาและไม่ลงเวลาในแอป (บันทึกการลานอกแอป)
- อนุมัติใบของตัวเองไม่ได้ / ไม่อนุมัติต้องใส่เหตุผล / อนุมัติแล้วใบล็อก
- ทุกการอนุมัติมีชื่อ บทบาท และเวลา (ดูได้ที่ "ประวัติการอนุมัติ" ในใบลา)
- พนักงานที่ไม่มีมือถือ: กด **ยื่นใบลาแทนพนักงาน**

## ตั้งค่า (ตั้งค่าตัวเลือก → กฎและอัตรา)

ผู้จัดการแผนกขึ้นไป/ผู้ดูแลระบบสูงสุดแก้ได้ ทุกค่ามี **วันที่เริ่มใช้** (ค่าเก่ายังใช้กับวันก่อนหน้า ไม่ย้อนแก้ข้อมูลเก่า):

| ค่า | ค่าเริ่มต้น |
|---|---|
| เวลาผ่อนผันก่อนนับว่าสาย / ออกก่อน | 0 นาที |
| เลยเวลาเลิกกะกี่ชั่วโมงจึงนับว่าลืมออก | 4 ชั่วโมง |
| ความคลาดเคลื่อน GPS สูงสุด | 150 เมตร |
| ขอแก้เวลาย้อนหลังได้ไม่เกิน | 31 วัน |
| ลาตั้งแต่กี่วันต้องให้ผู้จัดการแผนกขึ้นไปอนุมัติ | 4 วัน (ตามแอปเดิม) |
| โควตาวันลาต่อปี | ป่วย 30, กิจ 6, พักผ่อน 6, บวช 30 · **ตั้งแต่ 7 ธ.ค. 2568: คลอด 120, ช่วยภรรยาคลอดบุตร 15, ดูแลบุตรต่อจากลาคลอด 15** (ก่อนหน้านั้นคลอด 90 ตามแอปเดิม) |
| ประเภทลาที่แนบเอกสารได้ | ลาป่วย · ลาดูแลบุตรต่อจากลาคลอด (ต้องมีใบรับรองแพทย์) |

- **โควตารายคน:** แอดมินคลังขึ้นไปตั้งได้ในหน้าเดียวกัน (เช่น อายุงานครบปีได้พักร้อนเพิ่ม)
- **รัศมีคลัง:** ตั้งในหน้า "คลัง" ตอนนี้คลัง 5 และคลัง 32 ตั้งไว้ 200 เมตร
- **ตั้งพิกัดคลังจากมือถือ (แม่นที่สุด):** หน้า "คลัง" → ปุ่ม **"ตั้งพิกัดจากจุดที่ฉันยืนอยู่"** บนการ์ดคลัง (หรือในฟอร์มแก้ไข: "ใช้ตำแหน่งปัจจุบันของฉัน")
  1. ถือมือถือไปยืนที่จุดกลางคลัง หรือจุดที่พนักงานกดลงเวลา (ที่โล่งจะแม่นกว่าในอาคาร) แล้วกดปุ่ม
  2. แอปจับ GPS ต่อเนื่องสูงสุด 30 วินาที ตัดค่าช่วงแรกที่ยังคลาดเคลื่อนมากทิ้ง แล้วเฉลี่ยเฉพาะค่าที่แม่น (หยุดเองเมื่อได้ค่าแม่นถึง ±10 ม. 3 ครั้ง หรือกด "ใช้ค่านี้เลย")
  3. ดูความคลาดเคลื่อน (±ม.) และระยะห่างจากพิกัดเดิม กด "เปิด Google Maps" ตรวจจุดได้ แล้วกด **บันทึก** (ยังไม่กดบันทึก = ยังไม่เปลี่ยน)
  - ถ้าขึ้นเตือน "ยังคลาดเคลื่อนมาก" (เกิน ±30 ม.) ให้ออกไปที่โล่ง เปิด GPS แล้วกดใหม่ · ใช้ได้เฉพาะผู้ที่แก้ไขคลังได้

**ปรับตาม พ.ร.บ.คุ้มครองแรงงาน (ฉบับที่ 9) พ.ศ. 2568 (มีผล 7 ธ.ค. 2568):** ลาคลอด 120 วัน (มาตรา 41) นายจ้างจ่ายค่าจ้างไม่เกิน 60 วัน (มาตรา 59) ·
ลาช่วยภรรยาคลอดบุตร 15 วัน ใช้ภายใน 90 วันนับแต่วันคลอด ได้ค่าจ้าง (มาตรา 41/1) · ลาดูแลบุตรต่อจากลาคลอด 15 วัน กรณีบุตรเจ็บป่วย/ผิดปกติ/พิการ ต้องมีใบรับรองแพทย์ (มาตรา 41 วรรคสี่)
แอปไม่ได้คิดเงินค่าจ้างช่วงลา ให้ฝ่ายบุคคลตรวจการจ่ายเงินตามกฎหมาย · "ขาดงาน" ไม่ใช่ประเภทลาแล้ว (ระบบคำนวณจากการลงเวลาเอง)
ตรวจอัตราล่าสุดกับกรมสวัสดิการและคุ้มครองแรงงานทุกครั้ง

⚠️ **ใบรับรองแพทย์เป็นข้อมูลสุขภาพ** (ข้อมูลอ่อนไหวตาม PDPA) ควรระบุในประกาศความเป็นส่วนตัวของบริษัท และกำหนดระยะเวลาเก็บ
