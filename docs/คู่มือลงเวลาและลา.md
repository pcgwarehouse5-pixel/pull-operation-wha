# คู่มือลงเวลาและลา (โมดูล 3–4)

## หน้าหลักของพนักงาน (สรุปของฉัน)
คนที่ลงเวลาเห็นการ์ดสรุปใต้ปุ่มลงเวลา แตะการ์ดเพื่อไปดูรายละเอียด:

| การ์ด | แสดง | แตะแล้วไปที่ |
|---|---|---|
| ตำแหน่งงานวันนี้ | ตำแหน่ง คลัง กะ เวลาพัก ที่หัวหน้าจัดให้ | ตำแหน่งงานวันนี้ |
| OT เดือนนี้ | ชั่วโมง OT ที่อนุมัติแล้ว แยกตามอัตรา + ชั่วโมงที่รออนุมัติ (นับตามวันที่ 1 ถึงวันนี้ของเดือนปฏิทิน) | ลงเวลา (ท้ายหน้า) |
| วันลาคงเหลือ | คงเหลือ / สิทธิ์ ของแต่ละประเภทลา ปีนี้ | ลางาน |
| ใบลาล่าสุด | 3 ใบล่าสุด พร้อมสถานะ | ลางาน |


## ลงเวลา (ทุกคน) — เมนู "ลงเวลา"

1. กด **เข้างาน** ตอนมาถึง และ **ออกงาน** ตอนกลับ
2. ครั้งแรกเบราว์เซอร์จะถามขอใช้ตำแหน่ง ให้กด **อนุญาต**
3. ต้องอยู่ **ในรัศมีของคลัง** เท่านั้น ถ้าอยู่นอกพื้นที่ ระบบไม่บันทึกและบอกว่าห่างกี่เมตร
4. เวลาที่บันทึกเป็นเวลาของเซิร์ฟเวอร์ แก้นาฬิกาในมือถือไม่มีผล
5. กะดึก (เช่น 20:00–05:00) กดออกตอนเช้า ระบบนับเป็นวันที่เริ่มกะให้เอง
6. ระบบเก็บพิกัดเฉพาะตอนกดลงเวลา ไม่ติดตามตำแหน่งตลอดเวลา และไม่ถ่ายรูป

**ลืมกด / GPS ใช้ไม่ได้:** กด **ขอแก้เวลา** ใส่เวลาเข้า-ออกและเหตุผล → หัวหน้างานอนุมัติ → เวลาถูกบันทึกและล็อก
(ขอย้อนหลังได้ตามจำนวนวันที่ตั้งไว้ ค่าเริ่มต้น 31 วัน)

## ติดตามการเข้างาน (หัวหน้างานขึ้นไป)

- **รายวัน:** มาแล้วกี่คน ต้องตามกี่คน (สาย / ยังไม่เข้า / ขาด / ลืมเข้า-ออก) กดกรองตามสถานะได้ และกด "แก้เวลาแทน" ได้
- **สรุปรายเดือน:** วันมาทำงาน สาย (ครั้ง/นาที) ออกก่อน ขาด ลืมเข้า-ออก ลา ทำงานวันหยุด ส่งออก CSV ได้
- **คำขอแก้เวลา:** อนุมัติ / ไม่อนุมัติ (ต้องใส่เหตุผล) — อนุมัติคำขอของตัวเองไม่ได้

สถานะคำนวณจาก **ตารางกะ + เวลาจริง + ใบลาที่อนุมัติ** ในฐานข้อมูลที่เดียว:

| สถานะ | ความหมาย |
|---|---|
| ปกติ | เข้า-ออกตามกะ (รวมเวลาผ่อนผันที่ตั้งไว้) |
| สาย / ออกก่อน | เกินเวลาผ่อนผัน แสดงจำนวนนาทีนับจากเวลาเริ่ม/เลิกกะ |
| ยังไม่เข้า | กะเริ่มแล้วแต่ยังไม่กดเข้า |
| ขาด | เลยเวลาเลิกกะแล้วไม่มีเวลาเข้า-ออกเลย |
| ลืมออก / ลืมเข้า | มีแค่เวลาเข้า หรือแค่เวลาออก |
| ลา / ลาครึ่งวัน | มีใบลาที่อนุมัติแล้ว |
| วันหยุด / ทำงานวันหยุด | กะเป็น OFF/HOL |

## ลางาน (ทุกคน) — เมนู "ลางาน"

1. ดู **วันลาคงเหลือ** แต่ละประเภท
2. กด **ยื่นใบลา** เลือกประเภท วันที่ เต็มวัน/ครึ่งเช้า/ครึ่งบ่าย และใส่เหตุผล
3. **จำนวนวันลานับเฉพาะวันทำงานตามตารางกะ** (ไม่นับ OFF/HOL) ถ้าเดือนนั้นยังไม่มีตารางกะ นับทุกวันยกเว้นวันนักขัตฤกษ์
4. ลาป่วยแนบ **ใบรับรองแพทย์** ได้ (รูปหรือ PDF ไม่เกิน 5 MB) เห็นเฉพาะเจ้าของ หัวหน้า และผู้อนุมัติ
5. ยกเลิกได้ทันทีถ้ายังไม่อนุมัติ ถ้าอนุมัติแล้วต้องกด **ขอยกเลิก** ให้ผู้อนุมัติกดยืนยัน
6. ลาเกินโควตายังยื่นได้ แต่ใบจะติดป้าย "เกินโควตา" ให้ผู้อนุมัติเห็น

## อนุมัติใบลา (หัวหน้างานขึ้นไป)

- **ขั้น 1:** ระดับถัดไปของผู้ลา — พนักงาน → หัวหน้างาน/แอดมินของคลังนั้น · หัวหน้างาน/แอดมิน → ผู้จัดการแผนกขึ้นไป · ผู้จัดการแผนก → ผู้จัดการฝ่ายขึ้นไป ([คู่มือบทบาทและลำดับอนุมัติ](คู่มือบทบาทและลำดับอนุมัติ.md))
- **ขั้น 2:** ถ้าลา **ตั้งแต่ 4 วัน** (ตั้งค่าได้) ต้องให้ **ผู้จัดการแผนกขึ้นไป** อนุมัติต่อ
- ผู้จัดการอนุมัติตั้งแต่ขั้นแรก = ครบทุกขั้น
- ผู้จัดการฝ่ายขึ้นไปไม่ใช้ระบบลาและไม่ลงเวลาในแอป (บันทึกการลานอกแอป)
- อนุมัติใบของตัวเองไม่ได้ / ไม่อนุมัติต้องใส่เหตุผล / อนุมัติแล้วใบล็อก
- ทุกการอนุมัติมีชื่อ บทบาท และเวลา (ดูได้ที่ "ประวัติการอนุมัติ" ในใบลา)
- พนักงานที่ไม่มีมือถือ: กด **ยื่นใบลาแทนพนักงาน**

## ตั้งค่า (ตั้งค่าตัวเลือก → กฎและอัตรา)

ผู้จัดการแผนกขึ้นไป/ผู้ดูแลระบบสูงสุดแก้ได้ ทุกค่ามี **วันที่เริ่มใช้** (ค่าเก่ายังใช้กับวันก่อนหน้า ไม่ย้อนแก้ข้อมูลเก่า):

| ค่า | ค่าเริ่มต้น |
|---|---|
| เวลาผ่อนผันก่อนนับว่าสาย / ออกก่อน | 0 นาที |
| เลยเวลาเลิกกะกี่ชั่วโมงจึงนับว่าลืมออก | 4 ชั่วโมง |
| ความคลาดเคลื่อน GPS สูงสุด | 150 เมตร |
| ขอแก้เวลาย้อนหลังได้ไม่เกิน | 31 วัน |
| ลาตั้งแต่กี่วันต้องให้ผู้จัดการแผนกขึ้นไปอนุมัติ | 4 วัน (ตามแอปเดิม) |
| โควตาวันลาต่อปี | ป่วย 30, กิจ 6, พักผ่อน 6, คลอด 90, บวช 30 (ตามแอปเดิม) |
| ประเภทลาที่แนบเอกสารได้ | ลาป่วย |

- **โควตารายคน:** แอดมินคลังขึ้นไปตั้งได้ในหน้าเดียวกัน (เช่น อายุงานครบปีได้พักร้อนเพิ่ม)
- **รัศมีคลัง:** ตั้งในหน้า "คลัง" ตอนนี้คลัง 5 และคลัง 32 ตั้งไว้ 200 เมตร

⚠️ **ก่อนใช้จริงให้ตรวจโควตากับกฎหมายล่าสุด** (กรมสวัสดิการและคุ้มครองแรงงาน) เช่น ลาคลอด ค่า 90 วันมาจากแอปเดิม ซึ่งอาจไม่ตรงกับกฎหมายฉบับแก้ไขล่าสุด

⚠️ **ใบรับรองแพทย์เป็นข้อมูลสุขภาพ** (ข้อมูลอ่อนไหวตาม PDPA) ควรระบุในประกาศความเป็นส่วนตัวของบริษัท และกำหนดระยะเวลาเก็บ
