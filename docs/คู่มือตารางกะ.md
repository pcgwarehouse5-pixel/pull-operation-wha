# คู่มือตารางกะ (โมดูล 2)

## ใครทำอะไรได้

| บทบาท | ทำได้ |
|---|---|
| พนักงาน | ดู "ตารางกะของฉัน" และเพื่อนร่วมคลัง (ชื่อ ชื่อเล่น ตำแหน่ง กะ) **เฉพาะเดือนที่ประกาศแล้ว** · ไม่เห็นตารางกะหัวหน้าคลัง |
| หัวหน้างาน / แอดมินคลัง | วางกะ แก้กะ ประกาศ/กลับเป็นร่าง ล้างเดือน ย้อนกลับ ของคลังที่ดูแล · ดูตารางกะหัวหน้าคลังได้อย่างเดียว |
| ผู้จัดการแผนกขึ้นไป / ผู้ดูแลระบบสูงสุด | ทำได้ทุกคลัง รวมถึงแก้และประกาศตารางกะหัวหน้าคลัง |
| แอดมินขึ้นไป | แก้ปฏิทินวันหยุดนักขัตฤกษ์ และรหัสกะ ในหน้า "ตั้งค่าตัวเลือก" |

## ขั้นตอนประจำเดือน

1. เมนู **ตารางกะ** → เลือกคลังและเดือน (ปุ่ม ‹ ›)
2. วางกะด้วย **เครื่องมือ** (ผลจะขึ้นในตารางเป็น "ยังไม่บันทึก" ให้ตรวจก่อน):
   - **วางกะอัตโนมัติ**: ใส่จำนวนคนที่ต้องการต่อกะต่อตำแหน่ง ระบบจัดให้พอดี คนที่เหลือเป็นวันหยุด เว้นเวลาพักระหว่างกะ และหมุนกะเช้า/ดึกตามรอบสัปดาห์
   - **คัดลอกจากเดือนก่อน**: ใช้กะของ 4 สัปดาห์ก่อน (วันในสัปดาห์ตรงกัน)
   - **ทำซ้ำรูปแบบ**: เช่น เช้า 5 วัน หยุด 2 วัน
   - **เติมกะหลายคน**: กะเดียวกันในช่วงวันที่/วันในสัปดาห์ที่เลือก เช่น OFF ทุกวันอาทิตย์
   - **เติมวันนักขัตฤกษ์**: ใส่ HOL ตามปฏิทินวันหยุด
   - **นำเข้าจาก Excel/CSV**: ไฟล์ที่ส่งออกจากหน้านี้ หรือคัดลอกจาก Excel มาวาง
3. แก้ในตาราง (ใช้เหมือน Excel บนคอม — ดูหัวข้อด้านล่าง) หรือบนมือถือแตะช่องเพื่อเลือกกะ
4. กด **บันทึก** ที่แถบด้านล่าง
5. ตรวจแถว "คนทำงาน/วัน" ด้านล่างตาราง แล้วกด **ประกาศให้พนักงานเห็น**
6. แก้กะหลังประกาศได้ พนักงานเห็นทันทีหลังบันทึก

## ตารางกะหัวหน้าคลัง

เมนู **ตารางกะหัวหน้าคลัง** แยกจากตารางกะปกติ

- **ใครอยู่ในตารางนี้:** คนที่ตำแหน่งอยู่ในรายการ "ตำแหน่งที่อยู่ในตารางกะหัวหน้าคลัง" (ค่าเริ่มต้น **Supervisor** แก้ได้ที่ ตั้งค่า → กฎและอัตรา → ตารางกะ) และผู้จัดการแผนก · คนกลุ่มนี้จะไม่ขึ้นในตารางกะปกติ
- **แก้/ประกาศได้:** เฉพาะผู้จัดการแผนกขึ้นไป (และผู้ดูแลระบบสูงสุด)
- **ดูได้:** หัวหน้างาน/แอดมินของคลัง (ดูอย่างเดียว แม้ยังเป็นร่าง) · หัวหน้าคลังด้วยกันเห็นเมื่อประกาศแล้ว · พนักงานทั่วไปไม่เห็น
- **ประกาศแยกกัน:** ประกาศตารางปกติไม่ทำให้หัวหน้าคลังเห็นกะตัวเอง ต้องให้ผู้จัดการประกาศตารางหัวหน้าคลังด้วย (แจ้งเตือนส่งเฉพาะหัวหน้าคลัง)
- ล้างทั้งเดือนในตารางปกติ ไม่ลบกะของหัวหน้าคลัง (และกลับกัน)
- เดือนที่ประกาศไปแล้วก่อนแยกตาราง (ต.ค.–พ.ย. 2569) ตั้งเป็น "ประกาศแล้ว" ในตารางหัวหน้าคลังด้วย หัวหน้าคลังจึงยังเห็นกะเดิม

## ใช้ตารางเหมือน Excel (บนคอม)

ในช่องแสดง **เวลาเข้า/ออก** (เช่น 08:00 / 17:00) แทนรหัสกะ วันหยุดแสดง "หยุด"

| ทำอะไร | วิธี |
|---|---|
| เลือกหลายช่อง | ลากเมาส์ / Shift+คลิก / คลิกชื่อคน = ทั้งแถว / คลิกหัววันที่ = ทั้งวัน / Ctrl+A = ทั้งหมด |
| เลื่อน | ลูกศร (Shift+ลูกศร = ขยายช่วง), Tab, Enter |
| ใส่กะ | พิมพ์ทับได้เลย: เวลา `8-17`, `08:00-17:00`, `7.30-16.30` หรือรหัสกะ หรือ `หยุด` แล้ว Enter (F2 = แก้ค่าเดิม) |
| ทำงานวันหยุด | พิมพ์ต่อท้าย `+OFF` / `+HOL` เช่น `8-17+HOL` หรือดับเบิลคลิกแล้วเลือก |
| คัดลอก / ตัด / วาง | Ctrl+C / Ctrl+X / Ctrl+V — วางข้อมูลที่คัดลอกจาก Excel ได้ / 1 ค่าวางลงหลายช่อง = เติมทุกช่อง |
| เติมซ้ำรูปแบบ | ลากจุดสี่เหลี่ยมมุมขวาล่างของกรอบ (เช่น เลือกทำงาน 5 วัน + หยุด 2 วัน แล้วลากไปทั้งเดือน) |
| ย้าย | ลากขอบกรอบไปวางที่ใหม่ (กด Ctrl ค้าง = คัดลอก) |
| ลบ | Delete |
| ย้อนกลับ / ทำซ้ำ | Ctrl+Z / Ctrl+Y |
| เมนู | คลิกขวา: คัดลอก วาง ลบ และปุ่มใส่กะด่วน |

- เวลาที่พิมพ์ต้องมีในรายการรหัสกะ (ตั้งค่าตัวเลือก → รหัสกะ) ถ้าเวลาเดียวกันมีหลายรหัส ระบบใช้รหัสที่อยู่ลำดับแรก
- ทุกการแก้ขึ้นเป็น "ยังไม่บันทึก" จนกว่าจะกดบันทึก

## กลุ่มตามตำแหน่ง
- รายชื่อแบ่งเป็นกลุ่มตามตำแหน่ง แถบหัวกลุ่มบอกจำนวนคน และจำนวนคนทำงานของกลุ่มในแต่ละวัน
- กดชื่อกลุ่ม = พับ/กาง · **ลาก ⋮⋮ ที่หัวกลุ่ม** หรือกด ▲▼ เพื่อเรียงลำดับ
- ลำดับกลุ่มบันทึกต่อคลัง หัวหน้าทุกคนในคลังเห็นลำดับเดียวกัน

## การทำงานในวันหยุด

ถ้าพนักงานต้องมาทำงานในวันหยุดประจำสัปดาห์หรือวันนักขัตฤกษ์ ให้ใส่กะทำงาน แล้วเลือก
"ทำงานวันหยุดประจำสัปดาห์" (ป้าย **ห**) หรือ "ทำงานวันนักขัตฤกษ์" (ป้าย **น**)
ข้อมูลนี้ใช้คิดค่าทำงานในวันหยุดในโมดูล OT (อัตราตั้งในหน้าตั้งค่าเมื่อทำโมดูล OT)
ในไฟล์ Excel เขียนเป็น `GN_5+OFF` หรือ `GN_5+HOL`

## พลาดแล้วแก้ยังไง

- ยังไม่บันทึก: กด **ยกเลิก** ที่แถบด้านล่าง
- บันทึกไปแล้ว: เครื่องมือ → **ประวัติและย้อนกลับ** → กด "ย้อนกลับ" (ช่องที่มีคนแก้ต่อแล้วจะไม่ถูกแตะ)
- ล้างทั้งเดือนไปแล้ว: ประวัติและย้อนกลับ → "คืนข้อมูล" (ใส่กลับเฉพาะช่องที่ยังว่าง)
- ทุกการบันทึก/ล้าง/ประกาศ มีบันทึกว่าใครทำ เมื่อไร

## ข้อควรรู้

- คนที่ตั้ง "ไม่แสดงในตารางกะ" ในทะเบียนพนักงาน จะไม่อยู่ในตาราง (ยกเว้นมีกะในเดือนนั้นแล้ว)
- รหัสกะที่ไม่มีเวลาเข้า-ออก (OFF, HOL ฯลฯ) นับเป็นวันหยุด ไม่นับเป็นวันทำงาน
- ตัวเลขในวางกะอัตโนมัติ (วันหยุดต่อสัปดาห์ ชั่วโมงพัก) เป็นค่าตั้งต้นการวางแผน แก้ได้ทุกครั้ง
  เวลาทำงานและวันหยุดต้องเป็นไปตามข้อบังคับการทำงานของบริษัทและ พ.ร.บ.คุ้มครองแรงงาน
  (ตรวจกับกรมสวัสดิการและคุ้มครองแรงงาน หรือนักกฎหมายแรงงาน)
- ตารางกะเดิมจากแอปเก่า (ต.ค.–พ.ย. 2569) ย้ายมาแล้ว และตั้งเป็น "ประกาศแล้ว"
