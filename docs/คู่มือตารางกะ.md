# คู่มือตารางกะ (โมดูล 2)

## ใครทำอะไรได้

| บทบาท | ทำได้ |
|---|---|
| พนักงาน | ดู "ตารางกะของฉัน" และเพื่อนร่วมคลัง (ชื่อ ชื่อเล่น ตำแหน่ง กะ) **เฉพาะเดือนที่ประกาศแล้ว** |
| หัวหน้างาน / แอดมินคลัง | วางกะ แก้กะ ประกาศ/กลับเป็นร่าง ล้างเดือน ย้อนกลับ ของคลังที่ดูแล |
| ผู้บริหาร / ผู้ดูแลระบบสูงสุด | ทำได้ทุกคลัง |
| แอดมินขึ้นไป | แก้ปฏิทินวันหยุดนักขัตฤกษ์ และรหัสกะ ในหน้า "ตั้งค่าตัวเลือก" |

## ขั้นตอนประจำเดือน

1. เมนู **ตารางกะ** → เลือกคลังและเดือน (ปุ่ม ‹ ›)
2. วางกะด้วย **เครื่องมือ** (ผลจะขึ้นในตารางเป็น "ยังไม่บันทึก" ให้ตรวจก่อน):
   - **วางกะอัตโนมัติ**: ใส่จำนวนคนที่ต้องการต่อกะต่อตำแหน่ง ระบบจัดให้พอดี คนที่เหลือเป็นวันหยุด เว้นเวลาพักระหว่างกะ และหมุนกะเช้า/ดึกตามรอบสัปดาห์
   - **คัดลอกจากเดือนก่อน**: ใช้กะของ 4 สัปดาห์ก่อน (วันในสัปดาห์ตรงกัน)
   - **ทำซ้ำรูปแบบ**: เช่น เช้า 5 วัน หยุด 2 วัน
   - **เติมกะหลายคน**: กะเดียวกันในช่วงวันที่/วันในสัปดาห์ที่เลือก เช่น OFF ทุกวันอาทิตย์
   - **เติมวันนักขัตฤกษ์**: ใส่ HOL ตามปฏิทินวันหยุด
   - **นำเข้าจาก Excel/CSV**: ไฟล์ที่ส่งออกจากหน้านี้ หรือคัดลอกจาก Excel มาวาง
3. แก้รายคน: กด **แก้ไขกะ** → เลือกกะ แล้วแตะช่อง (บนคอมลากเมาส์ทาหลายช่องได้) หรือแตะช่องเพื่อเลือกทีละช่อง
4. กด **บันทึก** ที่แถบด้านล่าง
5. ตรวจแถว "คนทำงาน/วัน" ด้านล่างตาราง แล้วกด **ประกาศให้พนักงานเห็น**
6. แก้กะหลังประกาศได้ พนักงานเห็นทันทีหลังบันทึก

## การทำงานในวันหยุด

ถ้าพนักงานต้องมาทำงานในวันหยุดประจำสัปดาห์หรือวันนักขัตฤกษ์ ให้ใส่กะทำงาน แล้วเลือก
"ทำงานวันหยุดประจำสัปดาห์" (ป้าย **ห**) หรือ "ทำงานวันนักขัตฤกษ์" (ป้าย **น**)
ข้อมูลนี้ใช้คิดค่าทำงานในวันหยุดในโมดูล OT (อัตราตั้งในหน้าตั้งค่าเมื่อทำโมดูล OT)
ในไฟล์ Excel เขียนเป็น `GN_5+OFF` หรือ `GN_5+HOL`

## พลาดแล้วแก้ยังไง

- ยังไม่บันทึก: กด **ยกเลิก** ที่แถบด้านล่าง
- บันทึกไปแล้ว: เครื่องมือ → **ประวัติและย้อนกลับ** → กด "ย้อนกลับ" (ช่องที่มีคนแก้ต่อแล้วจะไม่ถูกแตะ)
- ล้างทั้งเดือนไปแล้ว: ประวัติและย้อนกลับ → "คืนข้อมูล" (ใส่กลับเฉพาะช่องที่ยังว่าง)
- ทุกการบันทึก/ล้าง/ประกาศ มีบันทึกว่าใครทำ เมื่อไร

## ข้อควรรู้

- คนที่ตั้ง "ไม่แสดงในตารางกะ" ในทะเบียนพนักงาน จะไม่อยู่ในตาราง (ยกเว้นมีกะในเดือนนั้นแล้ว)
- รหัสกะที่ไม่มีเวลาเข้า-ออก (OFF, HOL ฯลฯ) นับเป็นวันหยุด ไม่นับเป็นวันทำงาน
- ตัวเลขในวางกะอัตโนมัติ (วันหยุดต่อสัปดาห์ ชั่วโมงพัก) เป็นค่าตั้งต้นการวางแผน แก้ได้ทุกครั้ง
  เวลาทำงานและวันหยุดต้องเป็นไปตามข้อบังคับการทำงานของบริษัทและ พ.ร.บ.คุ้มครองแรงงาน
  (ตรวจกับกรมสวัสดิการและคุ้มครองแรงงาน หรือนักกฎหมายแรงงาน)
- ตารางกะเดิมจากแอปเก่า (ต.ค.–พ.ย. 2569) ย้ายมาแล้ว และตั้งเป็น "ประกาศแล้ว"
