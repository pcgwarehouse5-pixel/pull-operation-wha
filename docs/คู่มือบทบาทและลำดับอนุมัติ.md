# คู่มือบทบาทและลำดับอนุมัติ

## บทบาททั้งหมด (เรียงจากต่ำไปสูง)

| บทบาท | เห็น/ดูแล | ลงเวลา · ตารางกะ · OT · ลา |
|---|---|---|
| พนักงาน | ข้อมูลตัวเอง ตารางกะของคลังตัวเอง (เดือนที่ประกาศแล้ว) | ใช้ครบ |
| หัวหน้างาน | พนักงานในคลังที่ดูแล | ใช้ครบ |
| แอดมินคลัง | พนักงานในคลังที่ได้รับมอบหมาย | ใช้ครบ |
| **ผู้จัดการแผนก** | **ทำได้ทุกอย่างทุกคลัง** | ใช้ครบ · อยู่ใน "ตารางกะหัวหน้าคลัง" |
| **ผู้จัดการฝ่าย** | ทำได้ทุกอย่างทุกคลัง | **ไม่ใช้** (ไม่อยู่ในตารางกะ ไม่ลงเวลา ไม่มี OT ไม่ใช้ระบบลา) |
| **รองผู้จัดการทั่วไป** | ทำได้ทุกอย่างทุกคลัง | ไม่ใช้ |
| **ผู้จัดการทั่วไป** | ทำได้ทุกอย่างทุกคลัง | ไม่ใช้ |
| ผู้ดูแลระบบสูงสุด | ทุกอย่าง (บัญชีระบบ ไม่ใช่พนักงานคลัง) | ไม่ใช้ |

- บทบาท "ผู้บริหาร" เดิม **เลิกใช้แล้ว** ให้ใช้บทบาทผู้จัดการแทน (ตั้งบทบาทผู้บริหารให้คนใหม่ไม่ได้)
- ตั้งบทบาทให้คนอื่นได้ **ต่ำกว่าตัวเองลงไป** และแก้คนที่ระดับเท่ากันหรือสูงกว่าไม่ได้
- เมื่อเลื่อนใครขึ้นเป็นผู้จัดการฝ่ายขึ้นไป: กะตั้งแต่วันนี้ของคนนั้นถูกลบ (กะที่ผ่านมาเก็บไว้) และปิด OT/ค่าเดินทาง/ลงเวลาอัตโนมัติให้เอง

## ใครอนุมัติคำขอของใคร (อนุมัติโดยระดับถัดไป)

ใช้กับ **ใบลา คำขอแก้เวลา และ OT**

| ผู้ยื่น | ผู้อนุมัติ |
|---|---|
| พนักงาน | หัวหน้างาน / แอดมินของคลังนั้น (หรือผู้จัดการขึ้นไป) |
| หัวหน้างาน / แอดมินคลัง | ผู้จัดการแผนกขึ้นไป |
| ผู้จัดการแผนก | ผู้จัดการฝ่ายขึ้นไป |

- ลา **ตั้งแต่ 4 วัน** (ตั้งค่าได้ที่ ตั้งค่า → กฎและอัตรา → ลา) ต้องผ่าน **ผู้จัดการแผนกขึ้นไป** เป็นขั้นที่ 2
- ผู้จัดการอนุมัติตั้งแต่ขั้นแรก = ครบทุกขั้น
- อนุมัติคำขอของตัวเองไม่ได้
- แจ้งเตือนส่งไปที่ **ระดับต่ำสุดที่อนุมัติได้** เท่านั้น (เช่น ใบลาพนักงานแจ้งหัวหน้างาน/แอดมิน ไม่รบกวนผู้จัดการ)
- ถ้าไม่มีใครในระดับนั้นเลย แจ้งผู้ดูแลระบบสูงสุดแทน
- หน้าอนุมัติจะขึ้นว่า "รอระดับที่สูงกว่าอนุมัติ" ถ้าคุณไม่มีสิทธิ์อนุมัติรายการนั้น

## ข้อควรรู้ด้านกฎหมายแรงงาน (ตรวจกับนักกฎหมายแรงงานก่อนใช้จริง)

- **OT ของผู้จัดการ:** พ.ร.บ.คุ้มครองแรงงาน มาตรา 65 ยกเว้นค่าล่วงเวลาให้ลูกจ้างบางประเภท เช่น ผู้มีอำนาจทำการแทนนายจ้างในเรื่องการจ้าง การให้บำเหน็จ การลดค่าจ้าง หรือการเลิกจ้าง — การตัดสินว่าตำแหน่งใดเข้าข้อยกเว้นขึ้นกับอำนาจหน้าที่จริง ไม่ใช่ชื่อตำแหน่ง ตรวจกับกรมสวัสดิการและคุ้มครองแรงงาน / นักกฎหมายแรงงาน
- **การลาของผู้จัดการฝ่ายขึ้นไป:** แอปไม่เก็บใบลาของกลุ่มนี้ แต่สิทธิลาตามกฎหมายยังมีอยู่ ต้องบันทึกการลาไว้นอกแอป (เช่น ฝ่ายบุคคล)
