# คู่มือทะเบียนพนักงาน (โมดูล 1)

## ใครทำอะไรได้

| บทบาท | ทำได้ |
|---|---|
| หัวหน้างาน | ดูรายชื่อและข้อมูลรายคนของคลังที่ดูแล (ดูอย่างเดียว) |
| แอดมินคลัง | ดู แก้ไข เพิ่ม นำเข้า Excel ส่งออก CSV ลาออก/คืนสภาพ รีเซ็ตรหัสผ่าน ของคลังที่ดูแล |
| ผู้บริหาร / ผู้ดูแลระบบสูงสุด | ทำได้ทุกคลัง |

## เปิดดูข้อมูลพนักงานรายคน

1. เมนู **ทะเบียนพนักงาน** → ค้นหาด้วยรหัส ชื่อ หรือชื่อเล่น (กรองคลัง สถานะ ตำแหน่ง ประเภทได้)
2. กดชื่อพนักงาน → ด้านบนเป็น **การ์ดสรุป**:
   รหัสพนักงาน · รหัสเงินเดือน · คลัง · ตำแหน่ง · ประเภทพนักงาน · นามสกุล · ทักษะ
3. ช่องที่ยังว่างจะเป็นกรอบสีเหลือง "ยังไม่กรอก" และมีแถบบอกว่าขาดอะไร
4. แอดมินแก้ได้ในแบบฟอร์มด้านล่าง แล้วกด **บันทึกข้อมูลและทักษะ** (การ์ดสรุปจะอัปเดตหลังบันทึก)
5. เปลี่ยนคลังหรือบทบาท ทำที่หน้า **ผู้ใช้และสิทธิ์**

## หาคนที่ข้อมูลยังไม่ครบ

- หน้าทะเบียนพนักงานมีปุ่มสีเหลือง **⚠ ข้อมูลไม่ครบ … คน · ดูรายชื่อ** กดแล้วแสดงเฉพาะคนที่ยังขาดข้อมูล
- หรือเลือกในช่องกรอง: "ข้อมูลไม่ครบ (ทุกช่อง)" / "ไม่มีรหัสเงินเดือน" / "ไม่มีนามสกุล" / "ไม่มีทักษะ" ฯลฯ
- ใต้ชื่อแต่ละคนจะบอกว่า "ยังไม่กรอก: …"
- ไฟล์ CSV ที่ส่งออกมีคอลัมน์ "จำนวนทักษะ" และ "ข้อมูลที่ยังขาด" ไว้ส่งต่อให้ทีมกรอก

### เกณฑ์ที่ระบบใช้ตรวจ
| ช่อง | ถือว่า "ขาด" เมื่อ |
|---|---|
| นามสกุล | ช่องนามสกุลว่าง **และ** ช่องชื่อมีคำเดียว (ถ้าชื่อเต็มอยู่ในช่องชื่อ เช่น พนักงาน MOU ถือว่าครบ) |
| รหัสเงินเดือน / ตำแหน่ง / ประเภทพนักงาน | ช่องว่าง |
| คลัง | ไม่มีคลัง (ยกเว้นผู้บริหาร) |
| ทักษะ | ยังไม่ได้เลือกทักษะเลย |

บัญชีผู้ดูแลระบบสูงสุดไม่ถูกตรวจ เพราะไม่ใช่พนักงานคลัง

## ข้อมูลส่วนบุคคล (PDPA)
- แอปเก็บเฉพาะข้อมูลที่ใช้ทำงาน ไม่เก็บเลขบัตรประชาชน ที่อยู่ หรือข้อมูลสุขภาพ
- ข้อมูลรายคนเห็นได้เฉพาะหัวหน้างานขึ้นไปในคลังที่ดูแล (ควบคุมในฐานข้อมูล)
- ส่งออก CSV เท่าที่จำเป็น และเก็บไฟล์ในที่ปลอดภัย
