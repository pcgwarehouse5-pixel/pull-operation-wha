# คู่มือ Pull Operation · ช่วงที่ 3 สรุปกำลังพล และดึงคน

ก่อนใช้: ตั้งค่าให้ครบ ([คู่มือตั้งค่า](คู่มือPull-ตั้งค่า.md)) และกรอกยอดงาน ([คู่มือกรอกยอดงาน](คู่มือPull-ยอดงานและคำนวณ.md))

## ใครทำอะไรได้
| บทบาท | ทำได้ |
|---|---|
| หัวหน้างาน / แอดมินคลัง | ดูคลังกลาง จอง และยกเลิกการจอง **เข้าคลังของตัวเอง** · เห็นว่าคนของคลังตัวเองถูกดึงไปที่ไหน |
| ผู้บริหาร / ผู้ดูแลระบบสูงสุด | ทุกคลัง |
| พนักงาน | เห็นวันที่ตัวเองถูกจองไปช่วยงาน (หน้าตารางกะของฉัน) และได้แจ้งเตือน |

## คลังกลาง (Central Workforce Pool)
- พนักงานและหัวหน้างานที่ยังทำงานอยู่ของ **ทุกคลังที่มีผู้ใช้ในระบบ** (ตอนนี้ WH5 + WH32)
- สถานะของแต่ละคนในวัน/กะที่เลือก:

| สถานะ | ความหมาย |
|---|---|
| **พร้อม** | มีกะทำงานในกะนั้นตามตารางกะ ไม่ได้ลา และยังไม่ถูกจอง |
| **จองแล้ว** | จองเข้าคลังนี้แล้ว |
| **ติดภารกิจ** | ถูกคลังอื่นจองไปแล้ว (บอกว่าคลังไหน) |
| **ไม่พร้อม** | ลา (รวมใบลาที่รออนุมัติ) / วันหยุด / ไม่มีกะ / เข้าอีกกะ |

- กะเช้า/กะดึก แยกจากเวลาเข้างานของรหัสกะ: ค่าเริ่มต้นเข้างาน 06:00–13:59 = กะเช้า (ตามแอปเดิม)
  แก้ได้ที่ ตั้งค่าตัวเลือก → กฎและอัตรา → Pull Operation
- **1 คน จองได้ 1 คลังต่อวัน** ระบบกันจองซ้ำ (แม้สองคลังกดพร้อมกัน)

## หน้าสรุปกำลังพลที่ต้องการ (เมนู Pull Operation → สรุปกำลังพล & ดึงคน)
1. เลือก **คลัง · วันที่ · กะ** ที่แถบด้านบน (ปุ่มนาฬิกา = รีเฟรช)
2. ตัวเลขด้านบน: กำลังคนทั้งหมด · ต้องการ · จองแล้ว · **รอจอง** (ยังต้องจองอีก) · คนคงเหลือ (ยังว่าง)
3. การ์ดตำแหน่ง: ต้องการ / จองแล้ว / รอจอง / คนเหลือ และแถบความคืบหน้า (แดง = ยังขาด, เขียว = ครบ)
4. **กดการ์ด** เพื่อไปดึงคนของตำแหน่งนั้น
5. ตารางด้านล่าง: สรุปทุกตำแหน่งพร้อมอัตราการจอง

ถ้ายังไม่กรอกยอดงาน จะไม่มีตัวเลข "ต้องการ" (แสดง —) แต่ยังดึงคนได้

## หน้าดึงกำลังคนทีละตำแหน่ง
1. ด้านบน: ต้องการ / จองแล้ว / ขาด
2. ซ้าย **รายชื่อพนักงาน** (เรียง: พร้อม → จองแล้ว → ติดภารกิจ → ไม่พร้อม) ค้นหาชื่อ/รหัส กรองคลังต้นทาง สถานะ และ "มีทักษะนี้/ทุกคน"
3. **แตะชื่อคนที่ "พร้อม"** เพื่อเลือก (เลือกได้หลายคน) ชื่อจะไปอยู่ช่องด้านขวา
4. ขวา **พนักงานที่เลือกแล้ว** ช่องเลข 1, 2, 3 … ตามจำนวนที่ต้องการ · กด ✕ เพื่อเอาออก
5. กด **บันทึกการจอง** (มือถือ: ปุ่มที่แถบด้านล่าง)
   - ระบบแจ้งพนักงาน และแจ้งหัวหน้าคลังต้นทาง (ถ้าดึงข้ามคลัง)
   - ถ้ามีคนที่เพิ่งถูกจองไปก่อน ระบบบันทึกคนที่เหลือ และบอกชื่อคนที่จองไม่ได้พร้อมเหตุผล

### ยกเลิกการจอง
กด ✕ ที่คนที่ "ยืนยันแล้ว" → เลือกเหตุผล (งานลดลง / เปลี่ยนแผนกำลังคน / พนักงานไม่พร้อม / จองผิด / อื่น ๆ) → ยืนยัน
ระบบแจ้งพนักงานว่ายกเลิก · เหตุผลแก้ได้ที่ ตั้งค่าตัวเลือก → เหตุผลยกเลิกจอง (Pull)

## กฎสำคัญ
- จองได้วันนี้และล่วงหน้าไม่เกิน 60 วัน · วันที่ผ่านไปแล้วดูได้อย่างเดียว (จอง/ยกเลิกไม่ได้)
- จองได้เฉพาะคนที่มีทักษะตรง และทักษะนั้นเปิดให้คลังนี้ดึง
- จองได้ทันที ไม่ต้องให้คลังต้นทางอนุมัติ (ตามที่ตกลง) — ระบบแจ้งคลังต้นทางให้รับทราบ
- คลังต้นทางยังไม่มีการกัน "จำนวนคนขั้นต่ำที่ต้องเหลือ" ควรประสานก่อนดึงคนจำนวนมาก
- ทุกการจอง/ยกเลิกมีบันทึกว่าใครทำ เมื่อไร

## ข้อมูลส่วนบุคคล (PDPA)
หน้าคลังกลางแสดงเฉพาะ ชื่อ ชื่อเล่น รหัส คลัง กะ ทักษะ และสถานะ (ไม่มีเบอร์โทร เลขบัตร หรือข้อมูลอื่น)
เหตุผล "ลา" แสดงแค่คำว่า "ลา" ไม่บอกประเภทการลา
