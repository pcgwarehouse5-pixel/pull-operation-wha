# คู่มือ Pull Operation · ช่วงที่ 2 กรอกยอดงาน และผลคำนวณกำลังคน

ต้องตั้งค่าให้ครบก่อน ดู [คู่มือตั้งค่า](คู่มือPull-ตั้งค่า.md)

## ใครทำอะไรได้
| บทบาท | ทำได้ |
|---|---|
| หัวหน้างาน | กรอก/แก้ยอดงานของคลังตัวเอง **วันนี้และล่วงหน้า** (ไม่เกิน 90 วัน) · ดูผลคำนวณ |
| แอดมินคลัง | เหมือนหัวหน้างาน + แก้ยอดงานของ **วันที่ผ่านไปแล้ว** ได้ |
| ผู้บริหาร / ผู้ดูแลระบบสูงสุด | ทุกคลัง |
| พนักงาน | ไม่เห็นยอดงานและผลคำนวณ |

## กรอกปริมาณงาน (เมนู Pull Operation → กรอกปริมาณงาน)
1. แถบด้านบน: เลือก **คลัง · วันที่ · กะ** (กะแสดงชั่วโมงต่อกะที่ใช้คำนวณ)
2. กรอกยอดงานคาดการณ์ของแต่ละประเภทงาน (หน่วยแสดงข้างช่อง) — **ไม่มีงานให้ใส่ 0** อย่าเว้นว่าง
   ใต้ช่องบอกว่ายอดนี้ใช้คำนวณทักษะไหน
   ตัวเลขมีคอมมาคั่นหลักพันให้อัตโนมัติขณะพิมพ์ (เช่น 18000 → 18,000) พิมพ์ทศนิยมได้ไม่เกิน 2 ตำแหน่ง
3. ด้านขวา **ผลคำนวณทันที** เปลี่ยนตามตัวเลขที่พิมพ์ (ยังไม่บันทึก)
4. กด **บันทึก & คำนวณอัตโนมัติ**
5. ด้านล่าง **แผนยอดงาน 7 วัน**: ช่องเขียว = กรอกครบ (ตัวเลข = คนที่ต้องการ) · เหลือง = กรอกบางส่วน · เทา = ยังไม่กรอก · กดช่องเพื่อเปิดวัน/กะนั้น

## ผลคำนวณกำลังคน (เมนู Pull Operation → ผลคำนวณกำลังคน)
- แสดงสูตร และตารางรายทักษะ: ปริมาณงาน · ชม./กะ · Productivity · ผลคำนวณ · **ต้องการ (ปัดขึ้น)**
- ทักษะที่ทำหลายประเภทงาน แสดงทีละงาน แล้ว **รวมก่อนปัดขึ้นครั้งเดียว**
- คลัง/วันที่/กะ ที่เลือกจำไว้ร่วมกับหน้ากรอกปริมาณงาน
- ตัวเลขในหน้านี้คำนวณในฐานข้อมูล (หน้าเว็บแก้ไม่ได้) ใช้ค่า Productivity และชั่วโมงที่มีผล ณ วันที่นั้น

## สูตร
```
คนที่ต้องการ = ปริมาณงาน ÷ (ชั่วโมงต่อกะ × Productivity)   → ปัดขึ้นเสมอ
```
| ตัวอย่าง (WH5 กะเช้า 8 ชม.) | คำนวณ | ต้องการ |
|---|---|---|
| RT รับ 400 พาเลท · 25/ชม. | 400 ÷ (8 × 25) = 2.00 | 2 คน |
| Picker จ่าย 1,200 ลัง · 45/ชม. | 1,200 ÷ (8 × 45) = 3.33 | 4 คน |
| Checker 500 รายการ · 30/ชม. | 500 ÷ (8 × 30) = 2.08 | 3 คน |
| **รวม** | | **9 คน** |

ทำไมปัดขึ้น: Picker 3 คนทำได้ 1,080 ลัง งานค้าง 120 ลัง ต้อง OT หรือค้างข้ามกะ · 4 คนทำได้ 1,440 ลัง จบตามแผน

## เมื่อไม่มีตัวเลข (แสดง —)
ระบบไม่ตีค่าที่ไม่รู้เป็น 0 (จะทำให้เข้าใจผิดว่าคนพอ) และบอกเหตุผล:
| เหตุผล | แก้ที่ |
|---|---|
| ยังไม่กรอกยอดงาน | หน้ากรอกปริมาณงาน (ไม่มีงานใส่ 0) |
| ยังไม่ตั้ง Productivity | ตั้งค่า Pull → ขั้นที่ 2 (ตรวจวันที่เริ่มใช้ด้วย) |
| ยังไม่ตั้งชั่วโมงต่อกะ | ตั้งค่า Pull → ขั้นที่ 4 |
| ยังไม่ผูกประเภทงาน | ตั้งค่า Pull → ขั้นที่ 3 |

ยอด **รวมต้องการ** แสดงเมื่อคำนวณได้ครบทุกทักษะเท่านั้น

## ข้อควรรู้
- ทุกการบันทึก/แก้ยอดงานมีบันทึกว่าใครทำ เมื่อไร (หน้าประวัติการใช้งาน)
- ยอดงานโหลด/เช็คจ่ายเป็นชิ้น หัวหน้างานกรอกยอดชิ้นเอง
- ช่วงที่ 3 จะนำ "ต้องการ" ไปใช้ในหน้าสรุปกำลังพลและดึงคน (Pull Board)
