# คู่มือ Pull Operation · ช่วงที่ 4 Dashboard ผู้บริหาร และผังตำแหน่งพนักงาน

## Dashboard ผู้บริหาร (เมนู Pull Operation → Dashboard ผู้บริหาร · แอดมินคลังขึ้นไป)
ภาพรวมการจัดกำลังคนทุกคลังในหน้าเดียว — **ตัวเลขรวมเท่านั้น ไม่มีรายชื่อพนักงาน**

1. แถบด้านบน: เลือก **วันที่ · กะ (เช้า / ดึก / ทั้งวัน) · คลัง (ทุกคลัง หรือคลังเดียว)** · ปุ่มรีเฟรช
2. ตัวเลขหลัก 4 ช่อง:

| ช่อง | ความหมาย |
|---|---|
| กำลังคนใน Pool ทั้งหมด | พนักงาน/หัวหน้างานทุกคลังที่เข้ากะนั้นตามตารางกะ และไม่ได้ลา |
| ความต้องการ | รวมคนที่ต้องการของทุกคลัง (จากยอดงาน ÷ Productivity) และ % เทียบกำลังคน |
| จองแล้ว | รวมคนที่จองแล้วของทุกคลัง (รวมจัดคนในคลังตัวเอง) · บอกจำนวนที่ดึงข้ามคลัง |
| คงเหลือจากการจอง | กำลังคน − จองแล้ว (คนที่ยังว่าง) |

3. **ภาพรวมรายคลัง**: การ์ดต่อคลัง — ความต้องการ (และ % ของ Pool) · จองแล้ว (ดึงจากคลังอื่นกี่คน) · **ยังขาด** หรือ **ครบแล้ว** · ถูกดึงไปช่วยคลังอื่น · ลา
   - "ยังขาด" คิดรายทักษะ: ทักษะที่จองเกินไม่ชดเชยทักษะที่ยังขาด
4. **แนวโน้มย้อนหลัง 7 วัน**: แท่งคู่ ความต้องการ (น้ำเงิน) เทียบ จองแล้ว (เขียว) · ตัวเลขใต้วัน = % ใช้งาน Pool (จองแล้ว ÷ กำลังคน)
   - ชี้/แตะที่วัน = ดูตัวเลข · ปุ่ม **ดูเป็นตาราง** = ตัวเลขทุกวัน · บนมือถือเลื่อนกราฟซ้าย-ขวาได้
   - สีของกราฟผ่านการตรวจสำหรับผู้ที่ตาบอดสี

> คลังที่ยังไม่กรอกยอดงานหรือตั้งค่าไม่ครบ แสดง **—** (ไม่ตีเป็น 0) และมีแถบเตือนบอกจำนวนคลัง
> เพื่อไม่ให้เข้าใจผิดว่าคนพอ

## ผังตำแหน่งพนักงาน (เมนู Pull Operation → ผังตำแหน่งพนักงาน · หัวหน้างานขึ้นไป)
ใช้ประชุมก่อนเริ่มงาน: ทุกคนรู้ว่าตัวเองอยู่ตำแหน่งไหน และพักกี่โมง

1. เลือก **คลัง · วันที่ · กะ**
   - ด้านบนมี **แผนที่คลัง 3D** ของคลังที่เลือก (ตอนนี้มีผัง WH5 และ WH32) ใช้ชี้โซน ชั้นวาง Dock ตอนประชุม
   - ปุ่ม **มุม 3D / มุมหน้า / มุมบน** เปลี่ยนมุมกล้อง · ค่าเริ่มต้น **ล็อกมุมกล้อง** (บนมือถือเลื่อนหน้าผ่านแผนที่ได้)
   - กด **✎ หมุน/ซูมได้** เพื่อขยับเอง: คอม = ลากซ้ายเลื่อน · ลากขวาหมุน · ล้อเมาส์ซูม / มือถือ = นิ้วเดียวเลื่อน · สองนิ้วหมุน/ซูม · กด **🔒 ล็อกมุม** เพื่อกลับมุมเดิม
   - กด **ซ่อนแผนที่** ถ้าไม่ใช้ (เครื่องจำไว้ครั้งต่อไป) · ผังเป็นตำแหน่งโดยประมาณจากแบบ Layout ไม่ใช่แบบก่อสร้าง
   - **คนที่จองแล้วขึ้นเป็นจุดสีบนพื้น + ป้ายรูปการ์ตูนหน้าชื่อ** (รูปคนใส่หมวกนิรภัย/เสื้อกั๊ก สีตามตำแหน่งงาน รูปเดียวกับการ์ดด้านล่าง · ไม่มีตัวคน 3D แล้ว เพราะบางมุมกล้องมองไม่เห็น)
     มีป้ายหัวกลุ่ม เช่น "RT รับ · 3 คน" และป้ายรายคน **รูปการ์ตูน + ชื่อเล่น + เวลาพัก 2 รอบ** (เช่น พัก 11:00 · 16:30) (สีเดียวกับการ์ด · ยังไม่ตั้ง = "ยังไม่ตั้งเวลาพัก") แสดงเมื่อบนแผนที่ไม่เกิน 16 คน หรือซูมเข้าใกล้
   - **ขนาดใหญ่สำหรับแคปขึ้นบอร์ดประชุม:** รูปการ์ตูน ป้ายชื่อ/เวลาพัก และจุดบนพื้นใหญ่ 2 เท่าของรุ่นแรกเมื่อเปิดบนจอคอม (แผนที่กว้างตั้งแต่ ~1,100 px)
     จอแท็บเล็ต/มือถือป้ายย่อลงเล็กน้อยไม่ให้บังแผนที่ · ภาพที่ "บันทึกภาพ" ได้ขนาดเดียวกับบนจอ · แนะนำแคปจากจอคอม
     ผังที่ลากวางไว้ก่อนขยาย ถ้าตัวคนชิดกันเกินไป กด **↺ จัดเรียงใหม่อัตโนมัติ** (ระบบเว้นระยะใหม่ให้กว้างขึ้น)
   - **ตัวกรองก่อนแสดง:** "พนักงานจากคลัง" (ทั้งหมด / WH5 / WH32 = คลังต้นทางของคนที่ดึงมา)
     และ **"ติ๊กเลือกตำแหน่งที่จะแสดงในผัง"**: ติ๊กช่องหน้าตำแหน่ง = แสดงเฉพาะตำแหน่งที่ติ๊ก (ติ๊กได้หลายตำแหน่ง) · เอาติ๊กออก = ซ่อน
     ยังไม่ติ๊กเลย หรือกด **ล้าง (แสดงทุกตำแหน่ง)** = แสดงทั้งหมด · **การ์ดพนักงานด้านล่างแสดงเฉพาะตำแหน่งที่ติ๊กด้วย** (แคปทั้งแผนที่และการ์ดได้ตรงกัน)
   - กรองแล้ว **กล้องซูมเข้าหาคนกลุ่มนั้นให้เอง** ป้ายใหญ่ไม่ทับกัน (ยกเลิกกรอง = กลับทั้งคลัง)
   - **📷 บันทึกภาพ** = ได้ไฟล์ภาพ PNG ความละเอียดสูง (กว้าง ~1800 px) มีหัวกระดาษ คลัง · วันที่ · กะ · เวลาประชุม และรายการตำแหน่งพร้อมจำนวนคน
     ใช้ส่งกลุ่มหรือขึ้นจอตอนประชุมได้เลย · วิธีใช้แนะนำ: เลือก 1–2 ตำแหน่ง → บันทึกภาพ → เลือกตำแหน่งถัดไป → บันทึกภาพ ...
   - **จัดตำแหน่ง** (หัวหน้า/แอดมินของคลังนั้น · วันนี้หรือล่วงหน้า): กด **✋ จัดตำแหน่ง** แล้ว
     ลากป้ายชื่อหรือจุดบนพื้น = ย้ายรายคน · ลากป้ายสีหัวกลุ่ม = ย้ายทั้งกลุ่ม · ปล่อยมือแล้วระบบ **บันทึกทันที** ทุกเครื่องเห็นผังเดียวกัน · กด **✓ จัดเสร็จแล้ว** เพื่อกลับไปเลื่อนหน้าตามปกติ
   - คนที่ยังไม่เคยลาก ระบบวางให้เองตรง **จุดที่ตำแหน่งนั้นเคยวางล่าสุด** ในคลังนี้ (ครั้งแรกเรียงตามแนว UNLOADING AREA) · จัดครั้งเดียว วันต่อไปไม่ต้องลากใหม่
   - **↺ จัดเรียงใหม่อัตโนมัติ** = ล้างตำแหน่งที่ลากไว้ของคนที่แสดงอยู่ในรอบนี้ · แตะชื่อบนแผนที่ = ตั้งเวลาพัก (เหมือนแตะการ์ด)
   - ทุกการย้ายมีบันทึกประวัติว่าใครย้าย เมื่อไร · วันที่ผ่านไปแล้วดูได้อย่างเดียว
2. ซ้าย **เลือกตำแหน่งหลัก** (RT / Checker / OP / Picker / CT / โหลดสินค้า หรือทั้งหมด) และสรุปจำนวนคนต่อทักษะ เวลาเข้างาน
3. ขวา: คนที่จองแล้ว แยกตามทักษะ — การ์ดชื่อเล่น ตัวย่อ รหัส คลังที่มา (ถ้ามาจากคลังอื่น) และ **เวลาพัก** (สีตามเวลา)
4. **แตะการ์ด → เลือกเวลาพักรอบแรก** ระบบใส่รอบ 2 ให้เอง (หรือ "ล้างเวลาพัก") · พนักงานได้แจ้งเตือน และเห็นเวลาพักในเมนู **ตำแหน่งงานวันนี้**
5. ด้านล่าง (โหมดทั้งหมด): คนในคลังที่เข้ากะนี้แต่ยังไม่ได้จัดลงงาน → ไปจองที่หน้าดึงคน

- **เวลาพัก 2 รอบ แยกผลัด** (ตั้งที่ **ตั้งค่าตัวเลือก → เวลาพัก (Pull)**: ผลัด · เวลาพักรอบ 2 · หมายเหตุ) หน้าผังแสดงเฉพาะเวลาของผลัดที่เลือก

  | ผลัด | เลือกรอบแรก | รอบ 2 (ระบบใส่ให้) |
  |---|---|---|
  | เช้า | 11:00 | 16:30 (ก่อนเริ่ม OT) |
  | เช้า | 12:00 | 17:00 (ก่อนเริ่ม OT) |
  | เช้า | 13:00 | 17:30 (ก่อนเริ่ม OT) |
  | ดึก | 23:30 | 02:00 |
  | ดึก | 00:00 | 03:00 |
  | ดึก | 00:30 | 04:00 |

  การ์ดเรียงตามลำดับเวลาพักของผลัด · ถ้าคนไหนตั้งเวลาที่ไม่ใช่ของผลัดนั้นไว้ (ก่อนแยกผลัด) จะแสดงรอบแรกอย่างเดียว ให้เลือกใหม่
- วันที่ผ่านไปแล้วดูได้อย่างเดียว

## ตำแหน่งงานวันนี้ (เมนู ของฉัน → ตำแหน่งงานวันนี้ · พนักงานทุกคนที่ลงเวลา)
พนักงานเปิดดูบนมือถือได้เองว่า **วันนี้อยู่ตำแหน่งไหน คลังไหน กะไหน และพักกี่โมง** โดยไม่ต้องรอประชุม

1. การ์ดใหญ่ด้านบน = กะตอนนี้: ตำแหน่ง · คลัง · กะและเวลาเข้า-ออก · **เวลาพัก** (ตัวใหญ่สีเหลือง)
   - ถ้าถูกจองไปช่วยคลังอื่น มีแถบเตือน "ไปช่วยงานที่ … ไปรายงานตัวที่คลังนี้"
   - กะดึกข้ามเที่ยงคืน: หลังเที่ยงคืนยังแสดงกะเมื่อคืนจนกว่าจะถึงเวลาเลิกกะ
   - ยังไม่ได้จัด: ขึ้นว่า "หัวหน้ายังไม่ได้จัดตำแหน่งวันนี้" พร้อมเวลากะ ให้ถามหัวหน้างาน
2. ด้านล่าง = **วันถัดไป** (7 วัน) ที่หัวหน้าจัดไว้ล่วงหน้า พร้อมเวลาพัก
3. หน้าหลักของพนักงานมีการ์ดย่อ "ตำแหน่งงานวันนี้" และหน้าตารางกะของฉันมีรายการเดียวกัน

**แจ้งเตือน (กระดิ่งในแอป) ถึงพนักงาน**

| เมื่อหัวหน้า | พนักงานได้รับ |
|---|---|
| จัดลงตำแหน่งในคลังตัวเอง | หัวหน้าจัดตำแหน่งงานให้คุณ |
| จองไปช่วยคลังอื่น | คุณถูกจองไปช่วยงาน (หัวหน้าคลังต้นทางได้แจ้งด้วย) |
| ตั้งหรือเปลี่ยนเวลาพัก | เวลาพักของคุณ: พัก 11:00 และ 16:30 (ก่อนเริ่ม OT) (ตั้งค่าเดิมซ้ำ/ล้างเวลาพัก ไม่แจ้ง) |
| ยกเลิก | ยกเลิกตำแหน่งงานที่จัดไว้ / ยกเลิกการไปช่วยงาน |

- พนักงาน **เห็นเฉพาะของตัวเอง** ไม่เห็นตำแหน่งหรือเวลาพักของเพื่อน (กันไว้ในฐานข้อมูล)
- ตำแหน่งจะขึ้นก็ต่อเมื่อหัวหน้า **จองคนในหน้า "สรุปกำลังพล & ดึงคน"** (รวมคนในคลังตัวเอง) — ถ้าไม่จอง พนักงานจะไม่เห็นตำแหน่ง

### รุ่นแรก และสิ่งที่จะเพิ่มภายหลัง
- ใช้ **ตัวย่อชื่อแทนรูปถ่าย** และจัดเป็นกลุ่มตามทักษะ (ยังไม่วางบนแผนผังคลัง) ตามที่ตกลง
- ถ้าจะใช้รูปถ่ายพนักงาน: รูปถ่ายเป็นข้อมูลส่วนบุคคลตาม PDPA ต้องแจ้งวัตถุประสงค์ให้พนักงานทราบ
  จำกัดคนที่เห็น (หัวหน้างานของคลังนั้น) และเก็บในที่เก็บไฟล์แบบปิด — ปรึกษาก่อนเปิดใช้
- แผนผังคลัง (ภาพพื้นหลัง + จุดยืน) ต้องได้ภาพผังของแต่ละคลังก่อน
