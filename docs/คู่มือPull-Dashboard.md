# คู่มือ Pull Operation · ช่วงที่ 4 Dashboard ผู้บริหาร และผังตำแหน่งพนักงาน

## Dashboard ผู้บริหาร (เมนู Pull Operation → Dashboard ผู้บริหาร · แอดมินคลังขึ้นไป)
ภาพรวมการจัดกำลังคนทุกคลังในหน้าเดียว — **ตัวเลขรวมเท่านั้น ไม่มีรายชื่อพนักงาน**

1. แถบด้านบน: เลือก **วันที่ · กะ (เช้า / ดึก / ทั้งวัน) · คลัง (ทุกคลัง หรือคลังเดียว)** · ปุ่มรีเฟรช
2. ตัวเลขหลัก 4 ช่อง:

| ช่อง | ความหมาย |
|---|---|
| กำลังคนใน Pool ทั้งหมด | พนักงาน/หัวหน้างานทุกคลังที่เข้ากะนั้นตามตารางกะ และไม่ได้ลา |
| ความต้องการ | รวมคนที่ต้องการของทุกคลัง (จากยอดงาน ÷ Productivity) และ % เทียบกำลังคน |
| จองแล้ว | รวมคนที่จองแล้วของทุกคลัง (รวมจัดคนในคลังตัวเอง) · บอกจำนวนที่ดึงข้ามคลัง |
| คงเหลือจากการจอง | กำลังคน − จองแล้ว (คนที่ยังว่าง) |

3. **ภาพรวมรายคลัง**: การ์ดต่อคลัง — ความต้องการ (และ % ของ Pool) · จองแล้ว (ดึงจากคลังอื่นกี่คน) · **ยังขาด** หรือ **ครบแล้ว** · ถูกดึงไปช่วยคลังอื่น · ลา
   - "ยังขาด" คิดรายทักษะ: ทักษะที่จองเกินไม่ชดเชยทักษะที่ยังขาด
4. **แนวโน้มย้อนหลัง 7 วัน**: แท่งคู่ ความต้องการ (น้ำเงิน) เทียบ จองแล้ว (เขียว) · ตัวเลขใต้วัน = % ใช้งาน Pool (จองแล้ว ÷ กำลังคน)
   - ชี้/แตะที่วัน = ดูตัวเลข · ปุ่ม **ดูเป็นตาราง** = ตัวเลขทุกวัน · บนมือถือเลื่อนกราฟซ้าย-ขวาได้
   - สีของกราฟผ่านการตรวจสำหรับผู้ที่ตาบอดสี

> คลังที่ยังไม่กรอกยอดงานหรือตั้งค่าไม่ครบ แสดง **—** (ไม่ตีเป็น 0) และมีแถบเตือนบอกจำนวนคลัง
> เพื่อไม่ให้เข้าใจผิดว่าคนพอ

## ผังตำแหน่งพนักงาน (เมนู Pull Operation → ผังตำแหน่งพนักงาน · หัวหน้างานขึ้นไป)
ใช้ประชุมก่อนเริ่มงาน: ทุกคนรู้ว่าตัวเองอยู่ตำแหน่งไหน และพักกี่โมง

1. เลือก **คลัง · วันที่ · กะ**
2. ซ้าย **เลือกตำแหน่งหลัก** (RT / Checker / OP / Picker / CT / โหลดสินค้า หรือทั้งหมด) และสรุปจำนวนคนต่อทักษะ เวลาเข้างาน
3. ขวา: คนที่จองแล้ว แยกตามทักษะ — การ์ดชื่อเล่น ตัวย่อ รหัส คลังที่มา (ถ้ามาจากคลังอื่น) และ **เวลาพัก** (สีตามเวลา)
4. **แตะการ์ด → เลือกเวลาพัก** (หรือ "ล้างเวลาพัก") · พนักงานเห็นเวลาพักของตัวเอง
5. ด้านล่าง (โหมดทั้งหมด): คนในคลังที่เข้ากะนี้แต่ยังไม่ได้จัดลงงาน → ไปจองที่หน้าดึงคน

- เวลาพักที่เลือกได้ตั้งที่ **ตั้งค่าตัวเลือก → เวลาพัก (Pull)** ค่าเริ่มต้น 11:00 / 12:00 / 13:00 (ตามดีไซน์ที่นำเสนอ)
  **ยังไม่มีเวลาพักของกะดึก** ให้แอดมินเพิ่มตามที่คลังใช้จริง
- วันที่ผ่านไปแล้วดูได้อย่างเดียว

### รุ่นแรก และสิ่งที่จะเพิ่มภายหลัง
- ใช้ **ตัวย่อชื่อแทนรูปถ่าย** และจัดเป็นกลุ่มตามทักษะ (ยังไม่วางบนแผนผังคลัง) ตามที่ตกลง
- ถ้าจะใช้รูปถ่ายพนักงาน: รูปถ่ายเป็นข้อมูลส่วนบุคคลตาม PDPA ต้องแจ้งวัตถุประสงค์ให้พนักงานทราบ
  จำกัดคนที่เห็น (หัวหน้างานของคลังนั้น) และเก็บในที่เก็บไฟล์แบบปิด — ปรึกษาก่อนเปิดใช้
- แผนผังคลัง (ภาพพื้นหลัง + จุดยืน) ต้องได้ภาพผังของแต่ละคลังก่อน
