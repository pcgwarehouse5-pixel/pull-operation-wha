# คู่มือ OT / เบี้ยขยัน / ค่าเดินทาง / รายงาน / แจ้งเตือน (โมดูล 5, 7, 8)

## ⚠️ ทำก่อนเริ่มใช้จริง: ตั้ง "วันเริ่มใช้ลงเวลาในแอป"

ตั้งค่าตัวเลือก → กฎและอัตรา → ลงเวลา → **วันเริ่มใช้ลงเวลาในแอป**

- ก่อนวันนี้ (หรือยังไม่ได้ตั้ง) วันที่ไม่มีเวลาเข้า-ออกจะแสดง "ก่อนเริ่มใช้ลงเวลา" **ไม่นับขาดงาน ไม่แจ้งเตือน และไม่คิดเบี้ยขยัน**
- เหตุผล: ตารางกะเดิมที่ย้ายมาจากแอปเก่าไม่มีเวลาเข้า-ออก ถ้าไม่มีค่านี้ ทุกคนจะถูกนับว่าขาดงาน
- ตอนนี้ **ยังไม่ได้ตั้ง** → ตั้งเป็นวันที่พนักงานเริ่มกดลงเวลาจริง

## OT (เมนู "OT" — หัวหน้างานขึ้นไป)

1. ระบบ **คำนวณ OT จากเวลาเข้า-ออกจริง** ทุกวัน (แก้ตัวเลขจากหน้าเว็บไม่ได้)
2. หัวหน้าเลือกหลายรายการแล้วกด **อนุมัติ** หรือ **ไม่อนุมัติ** (ต้องใส่เหตุผล) — อนุมัติ OT ของตัวเองไม่ได้
3. ถ้าเวลาถูกแก้ภายหลัง (เช่น อนุมัติคำขอแก้เวลา) ตัวเลขเปลี่ยน → ขึ้น "เวลาเปลี่ยน รออนุมัติใหม่"
4. **รายงานนับเฉพาะ OT ที่อนุมัติแล้ว** · พนักงานดู OT ของตัวเองได้ในหน้า "ลงเวลา"

**กฎการคำนวณ (ตั้งค่าได้ทั้งหมด มีวันที่เริ่มใช้):**

| วัน | คิดอย่างไร |
|---|---|
| วันทำงาน | เวลาหลังเลิกกะ · **ไม่นับถ้าเกินไม่ถึง 60 นาที** · ปัดลงทีละ 30 นาที |
| วันหยุด (กะ OFF แดง/HOL, กะทำงานที่ทับ OFF แดง หรือ**กะทำงานในวันหยุดประจำปี — คิดให้อัตโนมัติ** · OFF เหลือง ไม่คิด) | ชั่วโมงปกติ (ไม่เกินชั่วโมงกะ หรือ 8 ชม. ถ้ากะไม่มีเวลา; หักพัก 60 นาทีเมื่อทำครบ 8 ชม.) คิดอัตราทำงานวันหยุด · ส่วนเกินคิดอัตรา OT วันหยุด |
| ไม่คิด OT | คนที่ปิด "คำนวณ OT" ในทะเบียน และกะที่เป็นเวรอาสา |

**อัตราเริ่มต้น (เท่าของค่าจ้างต่อชั่วโมง):**

| ประเภท | OT วันทำงาน | ทำงานวันหยุด | OT วันหยุด |
|---|---|---|---|
| ค่าเริ่มต้น (รายเดือน, MOU ฯลฯ) | 1.5 | 1 | 3 |
| คนงานรายวัน | 1.5 | 2 | 3 |

- ผลลัพธ์เป็น **ชั่วโมงแยกตามอัตรา** (OT 1 / 1.5 / 2 / 3) ฝ่ายเงินเดือนนำไปคูณค่าจ้างเอง (แอปไม่เก็บเงินเดือน)
- ⚠️ เกณฑ์ "ไม่นับถ้าไม่ถึง 60 นาที" เป็นการเลือกของบริษัท ถ้าพนักงานทำงานจริงตามคำสั่งหัวหน้า อาจถูกเรียกร้องได้ ปรึกษานักกฎหมายแรงงาน
- ⚠️ ตรวจอัตราทั้งหมดกับ พ.ร.บ.คุ้มครองแรงงานฉบับล่าสุด (กรมสวัสดิการและคุ้มครองแรงงาน) ก่อนใช้

## เบี้ยขยัน และค่าเดินทาง

- **รอบเงินเดือน:** ตั้งวันตัดรอบได้ (0 = ทั้งเดือน, 20 = 21 ของเดือนก่อน ถึง 20)
- **เบี้ยขยัน:** ขั้นบันได 300 → 400 → 500 บาท ตามจำนวนรอบติดกันที่ไม่มีเหตุ (ขาด / สาย / ลืมลงเวลา / ลาตามประเภทที่เลือก) มีเหตุ = รอบนั้นไม่ได้และเริ่มนับใหม่ · เลือกประเภทพนักงานที่ได้ได้
- **ค่าเดินทาง:** 30 บาท × วันที่มาทำงานจริง (มีเวลาเข้าหรือออก) เฉพาะคนที่ติ๊ก "ได้ค่าเดินทาง" ในทะเบียน
- ตัวเลขทั้งหมดตั้งที่ ตั้งค่าตัวเลือก → กฎและอัตรา → เบี้ยขยัน/ค่าเดินทาง

## รายงาน (เมนู "รายงาน" — หัวหน้างานขึ้นไป)

| แท็บ | มีอะไร |
|---|---|
| ภาพรวม | แต่ละคลัง: วันนี้ มา/สาย/ขาด/ลา · ตั้งแต่ต้นเดือน ขาด ลา ชั่วโมง OT และ OT ต่อคน |
| สรุป OT | ชั่วโมงแยกอัตรารายคน · **พิมพ์ใบ OT รายคน A4 พร้อมช่องลายเซ็น** (คนละหน้า) |
| เบี้ยขยัน / ค่าเดินทาง | รายคน + ยอดรวม |
| สรุปการลา | วันลาแยกประเภทรายคน (นับเฉพาะส่วนที่อยู่ในรอบ) |

ทุกแท็บ **ส่งออก CSV** (เปิดใน Excel ได้) และ **พิมพ์ A4** ได้

## แจ้งเตือน (กระดิ่งมุมขวาบน)

| เรื่อง | ใครได้รับ |
|---|---|
| ใบลา / คำขอแก้เวลารออนุมัติ | หัวหน้างาน/แอดมินของคลัง (ใบลาขั้นผู้บริหาร → ผู้บริหาร) |
| ผลอนุมัติใบลา / คำขอแก้เวลา | เจ้าของ |
| ประกาศตารางกะ | พนักงานในคลัง |
| ยังไม่ลงเวลาเข้า (กะเริ่มเกิน 30 นาที) / ลืมลงเวลาออก | พนักงาน |
| ขาดงานติดต่อกัน 3 วันทำงาน | หัวหน้างาน/แอดมิน — **เป็นการแจ้งให้ตรวจสอบ ไม่ได้ทำให้พ้นสภาพ** ต้องสอบถามเหตุผลและปรึกษาฝ่ายบุคคล/นักกฎหมายก่อนดำเนินการ |
| OT รออนุมัติ (สรุปวันละครั้ง) | หัวหน้างาน/แอดมิน |

- ระบบตรวจอัตโนมัติทุก 15 นาที (ทำงานในฐานข้อมูล ไม่เสียค่าใช้จ่ายเพิ่ม) และ **เริ่มทำงานหลังวันเริ่มใช้ลงเวลา**
- **Check In อัตโนมัติตามกะ:** เฉพาะคนที่แอดมินติ๊กไว้ในทะเบียน ระบบลงเวลาเข้าที่เวลาเริ่มกะให้ (ไม่ตรวจ GPS)
- ตอนนี้แจ้งเตือนเฉพาะในแอป ยังไม่ส่งเข้ามือถือ
