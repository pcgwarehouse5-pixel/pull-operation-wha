# คู่มือ "หน่วยงาน" (แยกข้อมูล WHA กับหน้าร้านคลัง 5)

ใช้แอปและลิงก์เดียวกัน แต่ข้อมูลของแต่ละหน่วยงานไม่ข้ามกัน

## กฎที่ใช้อยู่ (ระยะที่ 1 — ฐานข้อมูล, 27 พ.ย. 2569)
- ทุกคลังสังกัด 1 หน่วยงาน คลังเดิมทั้งหมด (คลัง 5, คลัง 32) อยู่หน่วยงาน **คลังสินค้า WHA** (หน่วยงานหลัก)
- พนักงานอยู่หน่วยงานของ "คลังหลัก" และ "คลังเพิ่มเติม" ของตัวเอง ส่วนคนที่ไม่มีคลังหลัก (ผู้จัดการฝ่ายขึ้นไป) อยู่หน่วยงานหลัก
- **ผู้จัดการทุกระดับเห็นได้ทุกคลังเฉพาะในหน่วยงานของตัวเอง** ไม่เห็นพนักงาน ตารางกะ เวลาเข้าออก ใบลา OT รายงาน หรือประวัติการใช้งานของหน่วยงานอื่น
- **ผู้ดูแลระบบสูงสุดเห็นทุกหน่วยงาน**
- **แอดมินที่ต้องดูแลทั้งสองฝั่ง:** ให้ตั้งคลังหลักไว้ฝั่งหนึ่ง แล้วใส่คลังของอีกฝั่งเป็น "คลังเพิ่มเติม" ก็จะเห็นและดูแลได้ทั้งสองฝั่ง
- **การอนุมัติและแจ้งเตือนอยู่ในหน่วยงานเดียวกัน** ถ้าหน่วยงานไม่มีผู้จัดการ ใบลาหรือ OT ของหัวหน้าจะไปหาผู้ดูแลระบบสูงสุด (ไม่ข้ามไปหาผู้จัดการ WHA)
- **ระบบดึงคน (Pull Operation)** ใช้ได้เฉพาะหน่วยงานที่เปิดเมนู Pull (WHA) คนของหน่วยงานอื่นจะไม่อยู่ในคลังกลาง ไม่ถูกจองข้ามหน่วยงาน และไม่ถูกนับในภาพรวม
- **ข้อมูลกลางที่ใช้ร่วมกัน** ได้แก่ อัตราและกฎ OT, รหัสกะ, ตัวเลือก, ทักษะ, วันหยุดประจำปี และประกาศ: ทุกหน่วยงานใช้ร่วมกัน แต่แก้ได้เฉพาะคนในหน่วยงานหลัก
- **เบี้ยขยัน:** ตั้งค่า `diligence.excluded_warehouses` (รายการรหัสคลังที่ไม่มีเบี้ยขยัน พร้อมวันเริ่มใช้) ตอนนี้ยังว่าง = ทุกคลังมีเบี้ยขยัน

## หน้าจอ (ระยะที่ 2, 27 พ.ย. 2569)
- **เมนู Pull Operation และ "ตำแหน่งงานวันนี้"** แสดงเฉพาะหน่วยงานที่เปิดใช้ Pull ถ้าคนหน่วยงานอื่นพิมพ์ลิงก์เข้ามาตรงๆ จะเห็นข้อความ "หน่วยงานของคุณไม่ได้ใช้เมนูนี้"
- **หน้า "คลัง" (เฉพาะผู้ดูแลระบบสูงสุด)** มีกล่อง "หน่วยงาน" ไว้เพิ่มหน่วยงาน แก้ชื่อ และติ๊กเปิด/ปิด Pull Operation (รหัสหน่วยงานตั้งได้ครั้งเดียวตอนสร้าง)
- **ฟอร์มคลัง** มีช่อง "หน่วยงาน" (เฉพาะผู้ดูแลระบบสูงสุด) และ "ใช้พิกัดเดียวกับคลัง" สำหรับคัดลอกพิกัดและรัศมีจากคลังอื่น เช่น หน้าร้านใช้จุดเดียวกับคลัง 5
  - ย้ายคลังไปหน่วยงานอื่น = พนักงานของคลังนั้นย้ายตามไปทั้งหมด
- **ตั้งค่า → กฎและอัตรา → เบี้ยขยัน/ค่าเดินทาง → "คลังที่ไม่มีเบี้ยขยัน"** เลือกคลังพร้อมวันเริ่มใช้

## หน้าร้านคลัง 5 (ระยะที่ 3, 27 พ.ย. 2569 — migration 0036)
- หน่วยงาน **SHOP5 · หน้าร้านคลัง 5** (ไม่ใช้ Pull Operation) และคลัง **WH5S · หน้าร้านคลัง 5**
- พิกัดและรัศมี Check In เดียวกับคลัง 5 (ถ้าคลัง 5 ย้ายพิกัด ต้องแก้ WH5S ด้วย)
- **ไม่มีเบี้ยขยัน**: ตั้งค่า "คลังที่ไม่มีเบี้ยขยัน" = WH5S เริ่ม 1 พ.ย. 2569
- **กฎ OT และวันหยุด** ใช้ชุดเดียวกับคลัง 5 (ข้อมูลกลาง)
- **หัวใบลงเวลา** ใช้ค่าเดียวกับคลัง 5 (เวอร์ชันเริ่ม 1 พ.ย. 2569) แก้แยกได้ในหน้า ตั้งค่า → กฎและอัตรา → ใบลงเวลา

### ขั้นตอนเริ่มใช้ (ผู้ดูแลระบบสูงสุดทำ)
1. **เพิ่มพนักงานหน้าร้าน:** ทะเบียนพนักงาน → เพิ่มทีละคน หรือนำเข้า Excel โดยให้คลัง = WH5S
2. **ตั้งหัวหน้าหน้าร้าน:** ผู้ใช้และสิทธิ์ → เลือกคน → บทบาท "หัวหน้างาน" คลังหลัก WH5S
3. **แอดมินที่ดูแลทั้งสองฝั่ง:** ผู้ใช้และสิทธิ์ → เลือกแอดมิน → เพิ่ม WH5S (หรือ WH5) เป็น "คลังเพิ่มเติม"
4. **คนอนุมัติใบลา/OT ของหัวหน้าหน้าร้าน:** ถ้ามีผู้จัดการ ให้ตั้งบทบาท "ผู้จัดการแผนก" คลังหลัก WH5S ถ้าไม่มี ใบจะไปหาผู้ดูแลระบบสูงสุด
5. หัวหน้าหน้าร้านวางตารางกะเดือนแรก แล้วกดประกาศ
6. ประกาศ (ป๊อปอัปภาพ) เป็นข้อมูลกลาง คนหน้าร้านจะเห็นประกาศเดียวกับ WHA

- ทดสอบกับฐานข้อมูลจริง: `node scripts/e2e-temp.mjs create` → `node scripts/e2e-storefront.mjs` → `node scripts/e2e-temp.mjs delete`
