# คู่มือ Pull Operation · ช่วงที่ 1 ตั้งค่าก่อนดึงคน

เมนู **Pull Operation → ตั้งค่า Pull** (แอดมินคลังขึ้นไป) · ตั้งค่าครั้งเดียว แก้ได้ตลอด ทุกค่ามี **วันที่เริ่มใช้**

## สูตรที่ระบบจะใช้ (ช่วงที่ 2)
```
คนที่ต้องการ = ปริมาณงาน ÷ (ชั่วโมงต่อกะ × Productivity)   → ปัดขึ้นเสมอ
```
ถ้าทักษะเดียวทำหลายประเภทงาน ระบบรวมผลของทุกงานก่อน แล้วปัดขึ้นครั้งเดียว

## ใครทำอะไรได้
| บทบาท | ทำได้ |
|---|---|
| แอดมินคลัง | ตั้งค่าทั้ง 4 ขั้นของคลังตัวเอง |
| ผู้บริหาร / ผู้ดูแลระบบสูงสุด | ตั้งค่าได้ทุกคลัง (ผู้ดูแลระบบสูงสุดตั้งวันที่ย้อนหลังได้) |
| หัวหน้างาน | ดูค่าที่ตั้งไว้ของคลังตัวเอง (ใช้ในหน้ากรอกยอดงาน/ดึงคน) |
| พนักงาน | ไม่เห็นการตั้งค่า |

## 4 ขั้นตอน (ปุ่มด้านบนมีเครื่องหมาย ✓ เมื่อขั้นนั้นครบ)
1. **ทักษะที่ดึงได้** — เปิดสวิตช์ทักษะที่คลังนี้ต้องการดึงคน แล้วกด **บันทึก** ที่แถบด้านล่าง
   - การ์ดบอกจำนวนคนที่มีทักษะนั้น (คลังนี้ / ทุกคลัง) · ตารางด้านขวาบอกว่าแต่ละคลังเปิดทักษะไหนบ้าง
   - รายการทักษะเพิ่ม/แก้ที่ ตั้งค่าตัวเลือก → ทักษะ · ทักษะของแต่ละคนตั้งที่หน้าทะเบียนพนักงาน
2. **Productivity** — 1 คนทำได้กี่หน่วยต่อชั่วโมง ระบบแสดง "1 คนทำได้ต่อกะ" ให้ทันทีขณะพิมพ์
   - แก้ตัวเลข → เลือก **เริ่มใช้** (วันนี้หรืออนาคต) → บันทึก · ค่าเก่ายังเก็บไว้ (ปุ่มนาฬิกา = ประวัติ)
   - ค่าที่ตั้งล่วงหน้าแต่ยังไม่ถึงวัน ลบได้ในหน้าประวัติ
3. **ผูกประเภทงาน** — ประเภทงาน (ที่หัวหน้างานจะกรอกยอด) → หน่วยนับ → ทักษะที่ใช้
   - กด **เพิ่มประเภทงาน** หรือ **แก้ไข** เลือกหน่วยนับ และติ๊กทักษะ (ต้องเปิดในขั้นที่ 1 ก่อน)
   - Productivity ใช้หน่วยของประเภทงานเสมอ จึงกรอกผิดหน่วยไม่ได้ · ตั้ง Productivity แล้ว **หน่วยจะล็อก** (จะใช้หน่วยอื่นให้สร้างประเภทงานใหม่)
   - ปิดประเภทงานที่เลิกใช้ได้ (ไม่ลบประวัติ)
4. **ชั่วโมงต่อกะ** — ชั่วโมงทำงานสุทธิ (หักพัก) ของกะเช้า/กะดึก แยกรายคลัง แก้ในตาราง เลือกวันที่เริ่มใช้ แล้วบันทึก

## ข้อควรรู้
- ค่าใหม่มีผลตั้งแต่วันที่เริ่มใช้ ผลคำนวณของวันก่อนหน้ายังใช้ค่าเดิม (ตรวจย้อนหลังได้)
- ทุกการแก้มีบันทึกว่าใครทำ เมื่อไร (หน้าประวัติการใช้งาน)
- หน่วยนับเพิ่มได้ที่ ตั้งค่าตัวเลือก → หน่วยนับปริมาณงาน (อย่าแก้ "ค่าในระบบ" ของหน่วยที่ใช้งานแล้ว)
- ตัวเลข Productivity และชั่วโมงควรให้ผู้บริหารอนุมัติเป็นมาตรฐานกลาง และให้แต่ละคลังยืนยันชั่วโมงสุทธิก่อนใช้งานจริง
