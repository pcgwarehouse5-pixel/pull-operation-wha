# คู่มือใบลงเวลา (พิมพ์ตามฟอร์มบริษัท)

เมนู **รายงาน → แท็บ "ใบลงเวลา"** · ใช้ได้เฉพาะหัวหน้างาน แอดมินคลัง และผู้จัดการ ของคลังนั้น

## ใช้ฟอร์มไหน

| ฟอร์ม | ใช้กับ | รอบ |
|---|---|---|
| **ฟอร์ม MOU** — "แบบฟอร์มการบันทึกเวลาปฏิบัติงาน และ แบบขออนุมัติทำงานล่วงเวลา คนงาน" | พนักงานประเภท **MOU** (ตามทะเบียนพนักงาน) | ครึ่งเดือนตามปฏิทิน: **วันที่ 1–15** หรือ **16–สิ้นเดือน** |
| **ฟอร์มคนไทย** — "แบบฟอร์มการบันทึกเวลาปฏิบัติงาน และ แบบขออนุมัติทำงานล่วงเวลา ทำงานวันหยุด และล่วงเวลาวันหยุด" | ทุกประเภทที่ไม่ใช่ MOU (พนักงานรายเดือน คนงานรายเดือน คนงานรายวัน ฯลฯ) | **เต็มเดือนเสมอ** · พิมพ์กลางเดือนได้ วันที่ยังไม่ถึงจะเป็นช่องว่าง |

## วิธีพิมพ์

1. เลือกคลัง (ถ้าดูแลหลายคลัง) และเดือน
2. เลือก **ฟอร์ม MOU** หรือ **ฟอร์มคนไทย** · ถ้าเป็น MOU เลือกรอบ 1–15 หรือ 16–สิ้นเดือน
3. ติ๊กเลือกพนักงาน (ระบบติ๊กให้ก่อนเฉพาะคนที่มีกะในรอบนั้น) · กด **เลือกทั้งหมด / ไม่เลือก** หรือค้นหาชื่อได้
4. กดชื่อในรายการเพื่อดูตัวอย่างใบของคนนั้น
5. กด **พิมพ์ใบลงเวลา N คน (A4)** → ได้คนละ 1 แผ่น
6. ที่หน้าต่างพิมพ์: กระดาษ **A4 แนวตั้ง** · ขนาด **100% (ไม่ย่อ/ขยาย)** · ระยะขอบ **ค่าเริ่มต้น** · ฟอร์มคนไทยใส่กระดาษสีเหลืองได้เลย (แอปพิมพ์พื้นขาว)

## ข้อมูลแต่ละช่องมาจากไหน

**ทั้ง 2 ฟอร์ม**
- **แถวสีเทา** = วันหยุดของพนักงานคนนั้นตามตารางกะ (รวมวันนักขัตฤกษ์)
- **ชั่วโมง OT** = เฉพาะ OT ที่ **อนุมัติแล้ว** ในหน้า OT · ถ้ายังมี OT รออนุมัติ หน้าจอจะเตือนก่อนพิมพ์ (ชั่วโมงนั้นจะไม่ขึ้นในใบ)
- ช่องลายเซ็นทุกช่องเว้นว่างไว้เซ็นมือ
- หมายเหตุ/เหตุผล ใส่ให้อัตโนมัติ: ประเภทลา (เช่น ลาป่วย, ลากิจ (ครึ่งเช้า)) · ขาดงาน · ไม่มีเวลาเข้า/ออก
- **หน้าร้าน (หน่วยงานที่เปิดแบบฟอร์มหน้าร้าน)**: วันที่มาสาย หมายเหตุขึ้น **"สาย N นาที"** (นับหลังเวลาผ่อนผัน · วันที่มีใบลาไม่ขึ้น)
- **เวลาในใบยึดตามตารางกะ (28 พ.ย. 2569)**: เข้าก่อนเวลากะ แสดงเวลาเข้ากะ (สแกน 07:50 กะ 08:00 → 08:00) · มาสายแสดงเวลาจริง · เวลาออก = เลิกกะ + ชั่วโมง OT ที่อนุมัติ (สแกน 20:05 → 20:00, 20:35 → 20:30) · ไม่มี OT อนุมัติ เวลาออกไม่เกินเวลาเลิกกะ · วันหยุด = เวลาเข้า + ชั่วโมงที่ได้ (+ พัก 1 ชม. ถ้าทำครบ 8 ชม.) — เวลาในใบจึงตรงกับชั่วโมงที่จ่ายเสมอ
- ชื่อใช้ คำนำหน้า + ชื่อ + นามสกุล ตามทะเบียน (ถ้าไม่ได้กรอกคำนำหน้า จะไม่มีคำนำหน้า)

**ฟอร์ม MOU**
- เวลาเข้า / เวลาออก = ตามตารางกะ (ดูด้านบน)
- **จำนวนแรงวันทำงาน** = 1 เมื่อมาทำงานในวันทำงานปกติ · 0.5 เมื่อลาครึ่งวัน · วันหยุดที่มาทำงานไม่นับในช่องนี้ (ไปอยู่ในช่อง OT)
- OT 1 / 1.5 / 2 / 3 = ชั่วโมงที่อนุมัติแล้วแยกตามอัตรา · ถ้ามีอัตราอื่นที่ฟอร์มไม่มีช่อง หน้าจอจะเตือนเป็นสีแดง

**ฟอร์มคนไทย**
- ช่วงเวลาที่ทำงานปกติ = เวลาเข้า (ตามกะ) ถึง เวลาเลิกกะ (ถ้าออกก่อนเลิกกะ ใช้เวลาออกจริง)
- ช่วงเวลาที่ทำ OT = เวลาเลิกกะ ถึง เลิกกะ + ชั่วโมง OT ที่อนุมัติ · วันหยุดที่มาทำงาน = เวลาเข้า ถึง เวลาเข้า + ชั่วโมงที่ได้
- OT. ปกติ / OT. วันหยุด / OT. วันหยุด = ชั่วโมง OT วันทำงาน / ชั่วโมงทำงานวันหยุด / OT วันหยุด · ตัวเลข "(… เท่า)" บนหัวคอลัมน์ แสดงตามอัตราจริงของประเภทพนักงานคนนั้น (ตั้งค่า → กฎและอัตรา → OT)

## ตั้งค่าข้อความในฟอร์ม

ตั้งค่า → **กฎและอัตรา** → กลุ่ม **ใบลงเวลา** (แก้ได้เฉพาะผู้บริหาร/ผู้ดูแลระบบสูงสุด) มีวันที่เริ่มใช้ทุกครั้ง
- ชื่อบริษัท ชื่อฟอร์ม เรื่อง เรียน และหมายเหตุท้ายฟอร์ม ของแต่ละฟอร์ม
- **ฝ่าย/แผนก และเลข UL ของแต่ละคลัง** (คลัง 5 ใส่ไว้ตามฟอร์มตัวอย่างแล้ว · **คลัง 32 ยังว่าง ต้องกรอกเอง**)

## ข้อควรระวัง
- ใบลงเวลามีข้อมูลส่วนบุคคล (ชื่อ รหัส เวลาเข้า-ออก วันลา) ตาม PDPA — เก็บเอกสารที่พิมพ์แล้วในที่ปลอดภัย และทำลายฉบับที่ไม่ใช้
- ถ้าเวลาในใบไม่ถูก ให้แก้ที่ต้นทาง (ขอแก้เวลา / อนุมัติ OT / ตารางกะ) แล้วพิมพ์ใหม่ ไม่ต้องแก้ในกระดาษ
