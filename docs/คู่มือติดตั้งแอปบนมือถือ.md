# คู่มือติดตั้งแอปบนมือถือ (Android / iPhone)

แอป WHA Workforce ติดตั้งบนหน้าจอมือถือได้เหมือนแอปทั่วไป **ไม่ต้องโหลดจาก Play Store / App Store และไม่มีค่าใช้จ่าย**
(เทคนิคเรียกว่า PWA: เว็บแอปที่ติดตั้งได้) เปิดจากไอคอนแล้วเต็มจอ ไม่มีแถบเบราว์เซอร์ และอัปเดตเป็นเวอร์ชันล่าสุดเองทุกครั้งที่เปิด

## มือถือที่รองรับ

| ระบบ | รองรับ | ตัวอย่างรุ่นที่ใช้ได้ | ใช้ไม่ได้ (เก่าเกินไป) |
|---|---|---|---|
| iPhone / iPad | iOS / iPadOS **15.4 ขึ้นไป** | iPhone 6s, 7, SE รุ่นแรก ขึ้นไป (อัปเดตได้ถึง iOS 15.8) | iPhone 6, 5s และเก่ากว่า (ค้างที่ iOS 12) |
| Android | **Chrome 99 ขึ้นไป** (Android 6 ขึ้นไป ที่อัปเดต Chrome แล้ว) | Samsung / OPPO / vivo / Xiaomi ที่อัปเดต Chrome ได้ | Android 5 และเก่ากว่า (Chrome ค้างที่รุ่น 95) |

เครื่องที่เก่ากว่านี้ แอปจะแสดงข้อความเตือนสีเหลือง "มือถือเครื่องนี้เก่ากว่าที่แอปรองรับ" ให้พนักงานอัปเดตระบบหรือ Chrome ก่อน

## แอปบอกวิธีเองตามเครื่อง

กล่อง **"ติดตั้งแอปบนมือถือ"** อยู่ที่ 3 ที่: หน้าเข้าสู่ระบบ (ใต้ปุ่มเข้าสู่ระบบ), หน้าหลัก และหน้า "ข้อมูลของฉัน"
แอปดูเองว่าพนักงานใช้มือถืออะไร แล้วแสดงวิธีที่ตรงกับเครื่องนั้น:

| เปิดจาก | สิ่งที่แอปแสดง |
|---|---|
| Android (Chrome / Samsung Internet) | ปุ่ม **"ติดตั้งแอป"** กดครั้งเดียวจบ · ถ้าเบราว์เซอร์ยังไม่พร้อม จะแสดง 3 ขั้นตอนผ่านเมนู ⋮ |
| iPhone / iPad (Safari) | 3 ขั้นตอน: กดปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" → "เพิ่ม" |
| iPhone ใน Chrome / แอปอื่น | ให้เปิดใน Safari พร้อมปุ่ม "คัดลอกลิงก์" |
| เปิดลิงก์ใน LINE | ปุ่ม **"เปิดใน Chrome / Safari"** (ติดตั้งจากใน LINE ไม่ได้) |
| Facebook / Messenger / TikTok | บอกให้กด ⋯ แล้วเลือก "เปิดในเบราว์เซอร์" |
| ติดตั้งแล้ว (เปิดจากไอคอน) | หน้าหลัก/หน้าล็อกอินไม่แสดงกล่องนี้อีก · หน้าข้อมูลของฉันขึ้นว่า "ติดตั้งแล้ว" |

พนักงานกด ✕ เพื่อซ่อนกล่องได้ จะไม่แสดงอีก 14 วัน (ยังดูวิธีได้ที่หน้า "ข้อมูลของฉัน" เสมอ)

## วิธีติดตั้งด้วยตัวเอง (ใช้สอนพนักงาน)

### Android
1. เปิด Chrome เข้า https://pull-operation-wha.vercel.app
2. กดปุ่ม "ติดตั้งแอป" ในกล่องของแอป หรือกด ⋮ มุมขวาบน แล้วเลือก "ติดตั้งแอป" / "เพิ่มลงในหน้าจอหลัก"
3. กด "ติดตั้ง" แล้วไอคอน WHA Workforce จะขึ้นบนหน้าจอ

### iPhone / iPad
1. เปิด **Safari** เข้า https://pull-operation-wha.vercel.app
2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) แถบล่างของ Safari
3. เลื่อนลง เลือก "เพิ่มไปยังหน้าจอโฮม" แล้วกด "เพิ่ม" มุมขวาบน

## คำถามที่พบบ่อย

- **ไม่มีเน็ตเปิดได้ไหม** — เปิดได้แต่จะเห็นหน้า "ไม่มีการเชื่อมต่ออินเทอร์เน็ต" พร้อมปุ่มลองใหม่ ข้อมูลทุกอย่าง (ลงเวลา ลา ตารางกะ) ต้องใช้เน็ต เพราะดึงจากฐานข้อมูลจริงทุกครั้ง
- **ต้องอัปเดตแอปเองไหม** — ไม่ต้อง เปิดแอปครั้งต่อไปจะได้เวอร์ชันล่าสุดเอง
- **ข้อมูลส่วนตัวถูกเก็บไว้ในมือถือไหม** — ไม่ แอปเก็บไว้ในเครื่องแค่หน้า "ไม่มีเน็ต" กับไอคอน ข้อมูลพนักงานไม่ถูกเก็บในเครื่อง
- **ลบแอป** — กดไอคอนค้าง แล้วเลือกลบ / เอาออก (ไม่กระทบข้อมูลในระบบ)

## สำหรับผู้ดูแลระบบ (เทคนิค)

- ไฟล์ที่เกี่ยวข้อง: `src/app/manifest.ts`, `public/sw.js`, `public/offline.html`, `src/lib/pwa.ts` (แยกประเภทเครื่อง + เกณฑ์รุ่นขั้นต่ำ), `src/components/pwa/InstallApp.tsx`
- รุ่นขั้นต่ำตั้งไว้ 2 ที่ ต้องแก้ให้ตรงกัน: `browserslist` ใน `package.json` และ `MIN_IOS` / `MIN_CHROME` ใน `src/lib/pwa.ts`
- `public/sw.js` เก็บแค่หน้าออฟไลน์และไอคอน ถ้าแก้ไฟล์นี้ให้เปลี่ยนชื่อ `CACHE` (เช่น `wha-shell-v2`) เพื่อล้างของเก่า
- เทสต์: `tests/pwa-lib.test.mjs`
